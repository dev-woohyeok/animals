# /animal-shorts-prompt - Sora2 프롬프트 생성

각 장면에 대한 Sora2 최적화 **한국어 프롬프트** 생성

## 사용법

```
/animal-shorts-prompt [장면 목록 참조]
```

---

## ⚠️ 핵심 원칙: Self-Contained 프롬프트

```yaml
핵심_문제: "Sora2는 각 프롬프트를 독립적으로 처리"
  - 이전 프롬프트 기억 안 함
  - character_reference 별도 참조 안 함
  - 각 영상 완전히 독립 생성

해결책: "모든 프롬프트가 독립적으로 완전한 정보 포함"
```

---

## Self-Contained 프롬프트 구조 (6단계)

### 모든 프롬프트에 반드시 포함할 요소:

```
1. 촬영 스타일   → 카메라 시점, 촬영 품질
2. 환경 설정     → 국가/지역, 장소, 날씨, 시간, 오브젝트
3. 동물 캐릭터   → 품종, 크기, 털 색상/상태, 눈, 액세서리 (매번 전체 설명!)
4. 인간 캐릭터   → 성별, 나이, 외모, 복장 (등장 시 매번 전체 설명!)
5. 씬 액션       → 구체적 행동, 감정/반응
6. 사운드        → No background music + 구체적 환경음/동물소리
```

---

## 프롬프트 작성 프로세스

### Step 1: 일관성 템플릿 정의 (프로젝트당 1회)

스토리 시작 시 **고정 요소** 정의:

```yaml
# 예시: 말티즈 유기/구조 스토리
consistency_template:
  animal:
    base: "작은 흰색 말티즈 한 마리. 약 3kg의 작은 성견."
    eyes: "크고 둥근 갈색 눈"
    accessory: "목에 작은 방울이 달린 분홍색 목줄"

  location:
    base: "미국 시애틀 교외"

  human_rescuer:
    base: "노란색 우비를 입은 여자(20대 후반, 갈색 포니테일)"

  sound:
    rule: "No background music"
```

### Step 2: 씬별 변화 요소 정의

```yaml
scene_variables:
  scene_1:
    fur: "깨끗하고 복슬복슬한 순백색 털"
    ribbon: "머리에 분홍색 리본"
    emotion: "혼란"
    weather: "늦가을 저녁, 가벼운 비"

  scene_4:
    fur: "하얀 털이 회색빛으로 지저분하게 엉킴. 마른 몸"
    ribbon: "없음"
    emotion: "두려움과 피로"
    weather: "비가 그친 흐린 아침"

  scene_10:
    fur: "깨끗하고 복슬복슬한 순백색 털로 돌아옴"
    ribbon: "새 분홍색 리본"
    emotion: "행복"
    weather: "화창한 낮"
```

### Step 3: 프롬프트 조립

**템플릿 + 변화요소 = 완성된 프롬프트**

```
[촬영 스타일]

[환경: location.base + scene.weather + 구체적 장소/오브젝트]

[동물: animal.base + animal.eyes + animal.accessory + scene.fur + scene.ribbon + scene.emotion]

[인간: human.base (등장 시)]

[씬 액션]

[사운드: sound.rule + 구체적 소리들]
```

## 프롬프트 예시

### 잘못된 예시 ❌

```
코기가 버림받고 비를 맞으며 떨고 있다.
```
→ Sora2: "어떤 코기? 어디서? 어떻게 생긴?"

### 올바른 예시 ✅

```
멀리서 목격하는 관찰 카메라 시점의 아마추어 핸드폰 영상. 길 건너편 행인이 촬영하는 듯한 원거리 샷, 줌인 사용.

미국 시애틀 교외의 한적한 주택가 도로. 늦가을 저녁, 가벼운 비가 내리고 있다. 젖은 아스팔트가 가로등 빛을 반사한다. 회색빛 흐린 하늘.

작은 흰색 말티즈 한 마리. 약 3kg의 작은 성견. 깨끗하고 복슬복슬한 순백색 털. 머리에 분홍색 리본. 목에 작은 방울이 달린 분홍색 목줄. 크고 둥근 갈색 눈.

30대 남자가 은색 세단에서 내린다. 비즈니스 캐주얼 복장, 스트레스 받은 표정. 말티즈를 안고 있다가 도로변에 내려놓는다. 아무 말 없이 차에 다시 타고 떠난다.

카메라가 줌인하며 강아지를 잡는다. 강아지가 고개를 갸웃하며 혼란스러워한다. 차가 출발하자 따라가려고 뛰기 시작한다. 차는 속도를 내며 사라진다.

No background music. 비 내리는 소리, 차 엔진 소리, 멀리서 희미하게 들리는 강아지의 작은 울음소리.
```

## 자막/캡션 규칙

**모든 장면에 영문 + 한글 자막 포함!**

```yaml
caption:
  EN: "He just... left her there."
  KR: "그냥... 버리고 갔어."
```

자막 작성 규칙:
- 1인칭 내레이션 스타일 (촬영자/구조자 시점)
- 짧고 임팩트 있게 (15자 내외)
- 감정을 자극하는 표현 사용

## 출력 형식

```yaml
# 일관성 템플릿
consistency_template:
  animal:
    base: "작은 흰색 말티즈 한 마리. 약 3kg의 작은 성견."
    eyes: "크고 둥근 갈색 눈"
    accessory: "목에 작은 방울이 달린 분홍색 목줄"
  location:
    base: "미국 시애틀 교외"
  human_rescuer:
    base: "노란색 우비를 입은 여자(20대 후반, 갈색 포니테일)"

# 씬별 프롬프트
prompts:
  - scene_id: 1
    title: "유기"
    duration: "15초"

    variables:
      fur: "깨끗하고 복슬복슬한 순백색 털"
      ribbon: "머리에 분홍색 리본"
      emotion: "혼란"
      weather: "늦가을 저녁, 가벼운 비"

    caption:
      EN: "He just... left her there."
      KR: "그냥... 버리고 갔어."

    prompt: |
      [전체 Self-Contained 프롬프트]

  - scene_id: 2
    ...
```

## 사운드 규칙 (중요!)

```
❌ "배경음악 없음, 소리 없음"
✅ "No background music. 코기 낑낑거리는 소리, 빗소리, 발소리."
```

자연스러운 소리는 반드시 포함:
- 동물 소리: 낑낑거림, 으르렁, 짖는 소리, 꼬리 흔드는 소리, 목줄 방울
- 사람 소리: 숨소리, 발소리, 부드러운 말소리, 한숨
- 환경음: 빗소리, 도시 소음, 새소리, 바람 소리, 문 여닫는 소리

## Content Policy 검증 (필수)

### 금지 표현

| 금지 | 대체 |
|-----|-----|
| 죽음, 시체 | 움직이지 않는, 쓰러진 |
| 피, 상처 | (삭제) |
| 공격, 죽이다 | (장면 분리) |
| 끔찍한, 무서운 | 긴장되는 |

## 프롬프트 체크리스트

각 프롬프트 생성 후 확인:

```
[ ] 촬영 스타일이 명시되어 있는가?
[ ] 환경/장소가 구체적으로 설명되어 있는가?
[ ] 동물 캐릭터의 전체 설명이 포함되어 있는가? (매번!)
[ ] 동물의 현재 상태(털, 감정)가 명시되어 있는가?
[ ] 인간 캐릭터 등장 시 외모/복장이 설명되어 있는가? (매번!)
[ ] 씬 액션이 구체적으로 묘사되어 있는가?
[ ] "No background music" + 구체적 소리가 포함되어 있는가?
[ ] 자막(EN/KR)이 포함되어 있는가?
[ ] 이 프롬프트만 보고 Sora2가 일관된 영상을 만들 수 있는가?
```

## DO / DON'T

### DO
- **한국어로 프롬프트 작성**
- **매 프롬프트에 캐릭터 전체 설명 포함** (복사-붙여넣기 OK)
- **매 프롬프트에 환경 설정 포함**
- **모든 장면에 자막 포함**
- 구체적이고 시각적인 설명 사용
- 자연스러운 소리 포함

### DON'T
- 영어로 프롬프트 작성
- "위와 동일한 캐릭터" 같은 참조 표현 사용 ❌
- "이전 씬에서 이어서" 같은 연결 표현 사용 ❌
- 자막 누락
- "beautiful", "nice" 같은 모호한 표현
- 배경음악 포함
- 200단어 초과
