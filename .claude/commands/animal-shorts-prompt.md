# /animal-shorts-prompt - Sora2 프롬프트 생성

각 장면에 대한 Sora2 최적화 **한국어 프롬프트** 생성 (멀티샷)

## 사용법

```
/animal-shorts-prompt [장면 목록 참조]
```

---

## ⚠️ 핵심 원칙: Self-Contained + Multi-Shot 프롬프트

```yaml
핵심_문제: "Sora2는 각 프롬프트를 독립적으로 처리"
  - 이전 프롬프트 기억 안 함
  - character_reference 별도 참조 안 함
  - 각 영상 완전히 독립 생성

해결책_1: "모든 프롬프트가 독립적으로 완전한 정보 포함"
해결책_2: "15초 안에 최대 3개 서브샷으로 다양한 시각 자극"
```

---

## ⚠️ Sora2 자유도 원칙 (CRITICAL)

```
핵심: "카메라는 상세하게, 상황은 간결하게"

상세하게 → 카메라 앵글, 움직임, 촬영 스타일, 캐릭터 외형
간결하게 → 상황/액션(한 줄), 감정(형용사 최소), 환경(핵심만)

❌ 금지: 감정 형용사 나열, 액션 과잉 묘사, 결과 예측
✅ 지향: 카메라 지시 정확 + 상황 한 줄 + Sora2에 해석 자유도
```

**간결한 프롬프트 = 높은 영상 퀄리티**

---

## Multi-Shot 프롬프트 구조 (7단계)

### 모든 프롬프트에 반드시 포함할 요소:

```
1. 스토리 컨텍스트   → ⚠️ CRITICAL! "// Story:" 로 시작. 아래 3가지 필수:
                       [전체] 전체 스토리 요약 1문장
                       [앞 장면] 직전 장면에서 무슨 일이 있었는지
                       [이 장면] 이 장면의 역할과 감정 방향
2. 촬영 스타일     → 카메라 시점, 촬영 품질, "여러 앵글 편집" 명시
3. 환경 설정       → 국가/지역, 장소, 날씨, 시간, 오브젝트
4. 동물 캐릭터     → 품종, 크기, 털 색상/상태, 눈, 액세서리 (매번 전체 설명!)
5. 인간 캐릭터     → 성별, 나이, 외모, 복장 (등장 시 매번 전체 설명!)
                      ⚠️ 1인칭 POV에서도 촬영자 캐릭터 필수! (손, 옷소매, 목소리 보임)
6. 서브샷 시퀀스   → 최대 3개 × 최대 5초씩. 5초 초과 금지!
                      Scene 2+: (0-5초) 서브샷1 / (5-10초) 서브샷2 / (10-15초) 서브샷3
7. 사운드          → No background music + 구체적 환경음/동물소리
```

### ⚠️ Story Context 예시

```
❌ 나쁜 예시 (이 장면만):
// Story: 병원에서 수술 후 깨어남. 그르렁거림.

✅ 좋은 예시 (전체 + 앞 장면 + 이 장면):
// Story: 전체: 3층 창문에서 던져진 고양이를 목격 → 구조 → 수술 → 6개월 후 행복.
앞 장면: 재킷으로 감싸 택시로 병원에 데려왔다.
이 장면: 수술 후 깁스를 한 고양이가 처음으로 그르렁거린다 — 고통에서 신뢰로 전환.
```

## 프롬프트 작성 프로세스

### Step 1: 일관성 템플릿 정의 (프로젝트당 1회)

스토리 시작 시 **고정 요소** 정의:

```yaml
consistency_template:
  animal:
    base: "작은 흰색 말티즈 한 마리. 약 3kg의 작은 성견."
    eyes: "크고 둥근 갈색 눈"
    accessory: "목에 작은 방울이 달린 분홍색 목줄"

  location:
    base: "미국 시애틀 교외"

  human_rescuer:
    base: "노란색 우비를 입은 여자(20대 후반, 갈색 포니테일)"

  sound:
    rule: "No background music"
```

### Step 2: 씬별 변화 요소 정의

```yaml
scene_variables:
  scene_1:
    fur: "깨끗하고 복슬복슬한 순백색 털"
    ribbon: "머리에 분홍색 리본"
    emotion: "혼란"
    weather: "늦가을 저녁, 가벼운 비"

  scene_4:
    fur: "하얀 털이 회색빛으로 지저분하게 엉킴. 마른 몸"
    ribbon: "없음"
    emotion: "두려움과 피로"
    weather: "비가 그친 흐린 아침"
```

### Step 3: 프롬프트 조립 (Multi-Shot 버전)

**템플릿 + 변화요소 + 서브샷 시퀀스 = 완성된 프롬프트**

```
[촬영 스타일 - "여러 앵글에서 편집한" 포함]

[환경: location.base + scene.weather + 구체적 장소/오브젝트]

[동물: animal.base + animal.eyes + animal.accessory + scene.fur + scene.emotion]

[인간: human.base (등장 시)]

[서브샷 시퀀스]
(0-Xs) [앵글] [액션]
(X-Ys) [앵글] [액션]
(Y-15초) [앵글] [액션]

[사운드: sound.rule + 구체적 소리들]
```

## 프롬프트 예시

### 잘못된 예시 ❌ (정보 부족)

```
코기가 버림받고 비를 맞으며 떨고 있다.
```
→ Sora2: "어떤 코기? 어디서? 어떻게 생긴? 어떤 앵글?"

### 잘못된 예시 ❌ (단일 샷)

```
1인칭 시점 핸드폰 영상.
미국 시애틀 교외...
코기가 벤치 아래에서 떨고 있다. 비에 젖어 있다. 카메라가 다가간다.
```
→ 15초 동안 한 장면만 = 단조롭고 이탈율 높음

### 잘못된 예시 ❌ (과도한 상세 - 퀄 떨어짐)

```
(0-2초) 강아지 눈 극단적 클로즈업. 빗물이 얼굴을 타고 흐른다. 번개가 번쩍이며 눈동자에 반사. 떨리는 눈. 공포에 질린 표정.
(2-5초) 카메라가 빠지면서 벤치 다리에 짧은 줄로 묶인 모습이 공개된다. 젖은 나무 벤치. 줄이 팽팽하게 당겨져 있다. 강아지가 몸을 웅크리고 있다.
```
→ 감정 형용사, 액션 과잉 묘사 = Sora2가 어색하게 해석

### 올바른 예시 ✅ (카메라 상세 + 상황 간결)

```
여러 앵글에서 편집한 아마추어 핸드폰 영상. 흔들리고 불안정. 핸드폰 플래시만.

미국 시애틀 교외 공원. 밤. 폭우. 나무 벤치. 가로등.

작은 흰색 말티즈 한 마리. 약 3kg 성견. 비에 젖은 하얀 털. 분홍색 목줄에 방울. 크고 둥근 갈색 눈.

(0-5초) 극단적 클로즈업. 강아지 눈. 빗물.
(5-10초) 풀백 미디엄. 벤치에 줄로 묶인 전신.
(10-15초) 슬로우 줌인. 강아지가 고개를 든다.

No background music. 폭우 소리, 천둥, 강아지 숨소리, 목줄 방울.
```

## 서브샷 시퀀스 규칙

```
⚠️ 모든 프롬프트에 참조 이미지 프레임 (0-1초) 필수!

Scene 2+:
  (0-1초) 참조 이미지 프레임.
  — 1초에 빠른 화면 전환 —
  (1-5초) → 서브샷 1
  — 전환: [촬영자의 물리적 카메라 동작] —
  (5-10초) → 서브샷 2
  — 전환: [촬영자의 물리적 카메라 동작] —
  (10-15초) → 서브샷 3

Scene 1 (Hook):
  (0-1초) 참조 이미지 프레임.
  — 1초에 빠른 화면 전환 —
  단일 연속 샷 14초
```

### ⚠️ 참조 이미지 프레임 규칙 (영구 고정)
- Sora2에 참조 이미지를 넣으면 첫 프레임이 해당 이미지 배경으로 시작
- 0-1초에 장면 설명을 넣어도 변경 불가 → 비워두고 후편집에서 잘라냄
- **모든 프롬프트에 (0-1초) 참조 이미지 프레임 고정 필수**

### ⚠️ 서브샷 간 전환 규칙 (영구 고정)
- 서브샷 사이에 촬영자의 물리적 카메라 동작 전환 필수
- 영화식 전환(cut, dissolve, fade) 금지
- 예: 폰 돌리기, 줌인, 내려놓기, 뒤집기 등

## 자막/캡션 규칙

**모든 장면에 영문 + 한글 자막 포함!**

```yaml
caption:
  EN: "He just... left her there."
  KR: "그냥... 버리고 갔어."
```

자막 작성 규칙:
- 1인칭 내레이션 스타일 (촬영자/구조자 시점)
- 짧고 임팩트 있게 (15자 내외)
- 감정을 자극하는 표현 사용

## 출력 형식

```yaml
# 일관성 템플릿
consistency_template:
  animal:
    base: "작은 흰색 말티즈 한 마리. 약 3kg의 작은 성견."
    eyes: "크고 둥근 갈색 눈"
    accessory: "목에 작은 방울이 달린 분홍색 목줄"
  location:
    base: "미국 시애틀 교외"
  human_rescuer:
    base: "노란색 우비를 입은 여자(20대 후반, 갈색 포니테일)"

# 씬별 프롬프트
prompts:
  - scene_id: 1
    title: "유기"
    is_hook: true
    duration: "15초"

    variables:
      fur: "깨끗하고 복슬복슬한 순백색 털"
      ribbon: "머리에 분홍색 리본"
      emotion: "혼란"
      weather: "늦가을 저녁, 가벼운 비"

    caption:
      EN: "He just... left her there."
      KR: "그냥... 버리고 갔어."

    prompt: |
      [전체 Self-Contained Multi-Shot 프롬프트]

  - scene_id: 2
    title: "비 속의 밤"
    is_hook: false
    duration: "15초"

    variables:
      fur: "비에 젖어 납작하게 붙은 털"
      emotion: "두려움"
      weather: "밤, 폭우"

    caption:
      EN: "She waited all night... in the rain"
      KR: "밤새 기다렸다... 빗속에서"

    prompt: |
      [전체 Self-Contained Multi-Shot 프롬프트]
```

## 사운드 규칙 (중요!)

```
❌ "배경음악 없음, 소리 없음"
✅ "No background music. 코기 낑낑거리는 소리, 빗소리, 발소리."
```

자연스러운 소리는 반드시 포함:
- 동물 소리: 낑낑거림, 으르렁, 짖는 소리, 꼬리 흔드는 소리, 목줄 방울
- 사람 소리: 숨소리, 발소리, 부드러운 말소리, 한숨
- 환경음: 빗소리, 도시 소음, 새소리, 바람 소리, 문 여닫는 소리

## 프롬프트 체크리스트

각 프롬프트 생성 후 확인:

```
[ ] (0-1초) 참조 이미지 프레임 + 1초 전환이 포함되어 있는가? (CRITICAL!)
[ ] 서브샷 사이에 "— 전환: [물리적 카메라 동작] —" 이 포함되어 있는가?
[ ] 촬영 스타일에 "여러 앵글/편집" 느낌이 명시되어 있는가?
[ ] 환경/장소가 구체적으로 설명되어 있는가?
[ ] 동물 캐릭터의 전체 설명이 포함되어 있는가? (매번!)
[ ] 동물의 현재 상태(털, 감정)가 명시되어 있는가?
[ ] 인간 캐릭터(촬영자 포함!) 외모/복장이 설명되어 있는가? (1인칭 POV = 촬영자 손/옷 필수!)
[ ] 서브샷 시퀀스가 (0-Xs) 형태로 시간순 작성되어 있는가?
[ ] 서브샷이 최대 3개이며 각각 앵글/구도 변화가 있는가?
[ ] "No background music" + 구체적 소리가 포함되어 있는가?
[ ] 자막(EN/KR)이 포함되어 있는가?
[ ] 이 프롬프트만 보고 Sora2가 일관된 영상을 만들 수 있는가?
```

## DO / DON'T

### DO
- **한국어로 프롬프트 작성**
- **매 프롬프트에 캐릭터 전체 설명 포함** (복사-붙여넣기 OK)
- **매 프롬프트에 환경 설정 포함**
- **서브샷 시퀀스를 (0-Xs) 형태로 시간순 작성**
- **모든 장면에 자막 포함**
- 구체적이고 시각적인 설명 사용
- 자연스러운 소리 포함

### DON'T
- 영어로 프롬프트 작성
- "위와 동일한 캐릭터" 같은 참조 표현 사용 ❌
- "이전 씬에서 이어서" 같은 연결 표현 사용 ❌
- 15초 동안 단일 앵글/단일 액션만 묘사 ❌
- 자막 누락
- "beautiful", "nice" 같은 모호한 표현
- 배경음악 포함
- 200단어 초과
