# /animal-shorts-prompt - Sora2 프롬프트 생성

각 장면에 대한 Sora2 최적화 **한국어 프롬프트** 생성

## 사용법

```
/animal-shorts-prompt [장면 목록 참조]
```

---

## 핵심 규칙

`prompts/sora2_system.md` 참조:

### 1. 캐릭터 일관성 (CRITICAL)

**모든 프롬프트에 동일한 캐릭터 설명 사용!**

```
[크기] [종] [털/깃털 색상과 질감], [눈 색상과 표현], [특징적인 특성]
```

**예시**:
```
주황색과 흰색 털을 가진 작은 펨브로크 웰시 코기 강아지, 짧고 뭉툭한 다리, 크고 쫑긋한 귀, 동그란 짙은 갈색 눈, 검은 코, 복슬복슬한 흰색 가슴 패치
```

### 2. 배경 일관성 (CRITICAL)

**스토리 전체에서 배경/환경 설정 일관성 유지!**

스토리 시작 시 배경 레퍼런스 정의:

```yaml
setting_reference:
  location: "도시 골목길 / 주택가"
  time_progression: "낮 → 저녁 → 밤 → 다음날"
  weather: "흐림 → 비 → 맑음"
  season: "가을"
```

각 장면에서 이 설정을 일관되게 반영:
- 같은 도시라면 비슷한 거리 스타일 유지
- 시간 흐름에 따른 조명 변화 자연스럽게
- 날씨 변화가 스토리와 연결되도록

### 3. 자막/캡션 필수 (CRITICAL)

**모든 장면에 영문 + 한글 자막 포함!**

```yaml
caption:
  EN: "He just left her there... I had to film this"
  KR: "그냥 버리고 갔어... 이건 찍어야 했다"
```

자막 작성 규칙:
- 1인칭 내레이션 스타일 (촬영자/구조자 시점)
- 짧고 임팩트 있게 (15자 내외)
- 감정을 자극하는 표현 사용
- 스토리 진행 상황 전달

### 4. 장면 컨텍스트 필수 (CRITICAL)

**각 장면에 앞뒤 상황 설명 포함!** AI 모델은 장면 간 연결을 모르므로 명확한 상황 설명 필요.

```yaml
context: "3일 전 버림받는 걸 목격한 코기를 찾아 헤매던 남자가 드디어 발견한 상황. 코기는 며칠간 거리를 헤매며 더 지치고 더러워진 상태"
```

컨텍스트 작성 규칙:
- **이전 장면에서 무슨 일이 있었는지** 설명
- **현재 상황**이 어떤 맥락인지 설명
- **캐릭터의 상태 변화** 포함 (경계 → 신뢰, 더러움 → 깨끗함 등)
- **시간 경과** 명시 (방금, 3일 후, 1년 후 등)

예시:
| Scene | Context 예시 |
|-------|-------------|
| 1 | 지나가던 남자가 우연히 유기 현장을 목격하고 멀리서 몰래 촬영하는 상황 |
| 2 | 방금 주인에게 버림받은 코기. 촬영자가 걱정되어 멀리서 따라가며 계속 촬영하는 상황 |
| 3 | 3일 전 유기 현장을 목격했던 남자가 그 코기를 다시 찾아 헤매다 발견한 상황 |
| 7 | 집으로 데려온 유기견을 처음 씻기는 상황. 며칠간 거리를 헤매서 더럽고 냄새나는 코기 |
| 8 | 1년이 지난 후. 처음에 사람을 경계하던 유기견이 이제 완전히 새 주인을 신뢰하고 행복한 가족이 된 상황 |

### 5. 프롬프트 구조 (순서대로)

1. **Camera/Style**: 카메라 스타일 (1인칭 시점 핸드폰 촬영)
2. **Context**: 상황 설명 (앞뒤 맥락)
3. **Character**: 캐릭터 설명 (일관되게 복사)
4. **Setting**: 환경/배경 (배경 레퍼런스 참조)
5. **Action**: 동작/움직임
6. **Camera Movement**: 카메라 움직임
7. **Lighting**: 조명
8. **Sound**: 자연스러운 소리 (배경음악 없음)

### 6. 품질 마커 (아마추어 스타일 고정)

```
1인칭 시점 손으로 들고 찍는 핸드폰 영상. 흔들리는 아마추어 촬영. 불안정한 카메라, 가끔 초점 나감. 배경음악 없음.
```

## DO / DON'T

### DO
- **한국어로 프롬프트 작성**
- 캐릭터 설명 **정확히 동일하게** 유지
- 배경 설정 **일관성 있게** 유지
- **모든 장면에 자막 포함**
- 구체적이고 시각적인 설명 사용
- 자연스러운 소리 포함 (동물 소리, 숨소리, 환경음)

### DON'T
- 영어로 프롬프트 작성
- 장면마다 캐릭터 설명 변경
- 배경 설정 불일치 (갑자기 다른 장소로)
- 자막 누락
- "beautiful", "nice" 같은 모호한 표현
- 배경음악 포함
- 200단어 초과

## 사운드 규칙 (중요!)

```
❌ "배경음악 없음, 소리 없음"
✅ "배경음악 없음, 코기 낑낑거리는 소리, 빗소리, 발소리만"
```

자연스러운 소리는 반드시 포함:
- 동물 소리: 낑낑거림, 으르렁, 짖는 소리
- 사람 소리: 숨소리, 발소리, 부드러운 말소리
- 환경음: 빗소리, 도시 소음, 새소리
