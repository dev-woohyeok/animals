# /animal-shorts-formula1 - 서프라이즈 공식 스토리 생성

> **S티어 공식**: "My [반려견]이 [야생동물]을 데려왔다"
> 채널 TOP 5 중 4개가 이 구조. 이종 동물 조합 + 1인칭 발견 스토리.

## 사용법

```
/animal-shorts-formula1 [동물]
```

### 예시
```
/animal-shorts-formula1 코기
/animal-shorts-formula1 골든 리트리버
/animal-shorts-formula1 핏불
```

---

## 공식 데이터 (채널 분석 기반)

### 성공 사례 (채널 실측 데이터 — 2026.04.20 기준)
| 조회수 | 제목 | 조합 | 좋아요율 |
|---:|---|---|---|
| 19.0M | Fox Tackled Me and Dragged Me Into the Woods | 여우 + 인간 | 2.0% |
| 6.2M | A stray pit bull guarded two kittens | 핏불 + 고양이 (이종 보호) | 7.1% |
| 4.0M | 3 AM My corgi brought a wolf | 코기 + 늑대 | 4.6% |
| 1.7M | My retriever found a tiny fox | 리트리버 + 여우 | 2.6% |
| ~500K | Fox came crying at midnight | 여우 + 야간 | - |

### 핵심 성공 요인
- **이종 동물 조합**: 반려견 + 야생동물이 핵심
- **여우 조연**: 여우가 등장하면 조회수 폭발 (채널 평균 305만뷰, 우선 배정)
- **1인칭 소유격 "My"**: 개인적 스토리 느낌 → 몰입감 극대화
- **시간 디테일**: "3 AM", "midnight" 같은 구체적 시간 → 현실감 + 긴장감 증폭
- **예상 밖의 행동**: 반려견이 뭔가를 물고/데리고 옴
- **이종 보호 반전**: 강한 동물(핏불)이 약한 동물(새끼고양이) 보호 → 인게이지먼트 최고 (7.1%)
- **60초 최적 길이**: 60초 전후 영상이 평균 조회수 96만, 75초 이상은 17만으로 급감

### 동물별 성과 (채널 실측)
| 동물 | 평균 조회수 | 등급 |
|------|-----------|------|
| **여우(Fox)** | 3,057,089 | S급 |
| **핏불(Pit bull)** | 6,200,000 | S급 |
| **코기(Corgi)** | 2,600,000 | S급 |
| **허스키(Husky)** | 1,258,867 | A급 |
| 골든 리트리버 | 17,567 | D급 (비추천) |

> ⚠️ 골든 리트리버는 채널에서 평균 1.7만뷰로 매우 저조. 너무 흔한 동물이라 차별화 어려움.

## 스토리 생성 로직

### 입력 처리
1. 입력된 동물을 **반려견 주인공**으로 배치
2. 야생동물 조연 자동 선택 (아래 우선순위)
3. 발견 상황 자동 생성
4. **스토리 3개 제안**

### 야생동물 조연 우선순위
```
1순위: 여우 (아기 여우, 부상 여우) — 채널 평균 305만뷰, 최고 19M
2순위: 늑대 (아기 늑대) — 4.0M 달성
3순위: 아기 고양이 — 6.2M 달성 (이종 보호 조합)
4순위: 너구리, 아기 사슴, 다람쥐, 아기 올빼미
5순위: 기타 야생동물 (토끼, 고슴도치 등)
```

### 서브 공식: 이종 동물 보호 (A티어 — 인게이지먼트 최강)
```
공식: "[강한 반려견]이 [약한 야생동물/새끼 동물]을 보호/지킴"
예시: "A stray pit bull guarded two kittens" (6.2M, 좋아요율 7.1%)

특징:
- 예상치 못한 동물 간 유대 → 공유 욕구 자극
- 좋아요율 7.1%로 채널 최고 수준
- 댓글 7,652개 — 감동 + 서프라이즈 동시 유발
- 반려견 주인공: 핏불, 로트와일러 등 "무서운 이미지" 견종일수록 반전 효과 ↑
```

### 발견 상황 자동 선택 (우선순위)
```
1순위: 새벽/야간 발견 — "3 AM", "midnight" (채널 데이터: 야간 영상 평균 83만뷰)
2순위: 산책/외출 중 발견 — 반려견이 물고/데리고 옴
3순위: 도그도어 침입 — 야생동물이 도그도어로 들어옴
4순위: 뒷마당 발견 — 뒷마당에서 야생동물 발견
5순위: 집 앞 발견 — 현관 앞에 야생동물이 앉아있음
```

## 감정 패턴 & 아키타입 (고정)

```yaml
emotional_pattern: u_curve
story_archetype: unexpected_bond
```

### 감정 곡선
```
놀라움/경계 → 당황/유머 → 호기심 → 유대 형성 → 이별 위기 → 재회/감동
```

### 5막 구조 (이 공식 전용)
```
1막 (도입): 반려견이 예상 밖의 야생동물을 데려옴. 주인 놀람.
2막 (전개): 야생동물과 반려견의 어색한 동거. 코믹 요소.
3막 (전환): 함께 먹고 자며 진짜 유대 형성. 따뜻함.
4막 (위기): 야생동물이 떠나야 하는 상황 (원래 서식지/부모).
5막 (결말): 성장한 야생동물이 다시 찾아옴. 변치 않은 유대.
```

## 제목 공식 (내장)

### 패턴 1: 소유격 + 행동 (최강)
```
"My [breed] [brought/found/came home with] a [wild animal]"
```

### 패턴 2: 시간 + 소유격 + 행동
```
"3 AM My [breed] [brought/found] a [wild animal]"
"Middle of the night, my [breed] [행동]"
```

### 패턴 3: 야생동물 주어
```
"[Wild animal] [Ran Through/Crawled Into] My [Dog Door/Backyard]"
"A [tiny/baby] [wild animal] [행동] and my [breed] [반응]"
```

## 출력 형식

**반드시 아래 형식으로 3가지 스토리 옵션 제안:**

```
📋 서프라이즈 공식 스토리 옵션:

🦊 1. 「[제목]」
   [반려견]이 [상황]에서 [야생동물]을 [행동].
   [2-3문장 시놉시스]
   📌 제목안: "[English title]"

🐺 2. 「[제목]」
   [반려견]이 [상황]에서 [야생동물]을 [행동].
   [2-3문장 시놉시스]
   📌 제목안: "[English title]"

🦝 3. 「[제목]」
   [반려견]이 [상황]에서 [야생동물]을 [행동].
   [2-3문장 시놉시스]
   📌 제목안: "[English title]"

→ 번호를 선택하세요.
```

### 스토리 옵션 규칙
- 3개 옵션은 서로 다른 야생동물 조연 사용
- 3개 옵션은 서로 다른 발견 상황 사용
- 각 옵션에 영어 제목안 포함 (제목 공식 적용)
- 여우 옵션 최소 1개 필수 포함

## 제약사항

### 필수
- 감정 패턴: `u_curve` 고정
- 스토리 아키타입: `unexpected_bond` 고정
- 야생동물 조연 필수 (단일 동물만 등장 금지)
- 이종 조합 필수
- 영어 제목
- 미국/북미 배경 (한국 장소 절대 금지)
- 시간순 전개만 (플래시백 금지)

### 금지
- 학대/유기 요소 (→ formula2의 영역)
- 동물 사망/부상 장면
- 비현실적 동물 행동 (판타지)
- 한국 장소/배경
