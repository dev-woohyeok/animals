# /animal-shorts-export - 파일 출력

최종 결과물을 Markdown 파일로 저장

## 사용법

```
/animal-shorts-export [프로젝트 데이터]
```

---

## 저장 위치

```
projects/{slug}/prompts.md
```

**slug 생성 규칙**:
- 한글 → 영문 변환 또는 그대로
- 공백 → 하이픈
- 소문자
- 날짜 추가 (YYYYMMDD)

예: `hedgehog-family-20250107`

---

## 출력 형식

`output/hedgehog_family.md` 참조:

```markdown
# {메인 제목}

> {synopsis}

**총 길이:** {total_duration}초 ({scene_count}개 장면)

---

## Scene 1: {title} ({title_en})

- **Duration:** {duration}s
- **Emotion:** {emotion}
- **Camera:** {camera.movement}, {camera.angle}
- **Lighting:** {lighting}

### Sora2 Prompt

\`\`\`
{english_prompt}
\`\`\`

---

## Scene 2: {title} ({title_en})

...

---

## 캐릭터 레퍼런스

> {character_reference}

모든 프롬프트에서 이 캐릭터 설명을 일관되게 사용합니다.

---

## 제목 옵션

**메인:** {main_title}

**부제목:** {subtitle}

- **YouTube:** {youtube_shorts}
- **Instagram:** {instagram_reels}
- **TikTok:** {tiktok}

### 후킹 옵션
- **감정형:** {hooks.emotional}
- **호기심형:** {hooks.curiosity}
- **결과형:** {hooks.outcome}

---

## 사용 방법

1. 각 Scene의 Sora2 Prompt를 복사
2. OpenAI Sora2에 붙여넣기
3. 생성된 영상 다운로드
4. 편집 소프트웨어에서 순서대로 배치
5. 선택한 플랫폼 제목으로 업로드

---

*Generated by Animal Shorts Agent System*
```

---

## 파일 저장 후 안내

저장 완료 후 다음 메시지 출력:

```
✅ 파일이 저장되었습니다!

📁 위치: projects/{slug}/prompts.md

📋 다음 단계:
1. 파일을 열어 프롬프트를 확인하세요
2. 각 Scene의 Sora2 Prompt를 복사하세요
3. OpenAI Sora2에서 영상을 생성하세요
4. 영상을 편집하고 업로드하세요

🎬 총 {scene_count}개 장면, {total_duration}초 분량입니다.
```
