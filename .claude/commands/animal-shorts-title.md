# /animal-shorts-title - 제목 생성

플랫폼별 최적화 바이럴 제목 생성

## 사용법

```
/animal-shorts-title [스토리 참조]
```

---

## 플랫폼별 전략

`prompts/title_system.md` 참조:

### YouTube Shorts
- **길이**: 100자 이내
- **특징**: 이모지 사용, "(실화)" 추가
- **톤**: 감정적, 클릭 유도
- **예시**: `골든 리트리버가 아기 고슴도치를 물어왔는데... 1년 후 놀라운 일이 (실화)`

### Instagram Reels
- **특징**: 세련된 톤, 미니멀 이모지
- **톤**: 감성적, 스토리텔링
- **예시**: `강아지가 데려온 아기 고슴도치의 1년 후 ✨ 솔방울 같은 아기들까지`

### TikTok
- **특징**: 구어체, 강한 후킹
- **톤**: 친근함, 직접 말하는 듯한
- **예시**: `골든리트리버가 입에 뭘 물고왔는데... 결말 보고 심장 녹음`

---

## 후킹 스타일 (3가지)

### 1. 감정형 (Emotional)
감정에 직접 호소
```
눈물 없이 못 보는 따뜻한 이야기
```

### 2. 호기심형 (Curiosity)
궁금증 유발
```
이 강아지에게 무슨 일이 있었을까?
```

### 3. 결과형 (Outcome)
결과 강조
```
기적 같은 결말의 버려진 강아지
```

```yaml
main_title: "솔방울 가족의 탄생"
subtitle: "골든 리트리버가 물어온 작은 기적"

  instagram_reels: "강아지가 데려온 아기 고슴도치의 1년 후 ✨ 솔방울 같은 아기들까지"
  tiktok: "골든리트리버가 입에 뭘 물고왔는데... 결말 보고 심장 녹음"

hooks:
  emotional: "눈물 없이 못 보는 따뜻한 이야기"
  curiosity: "이 강아지에게 무슨 일이 있었을까?"
  outcome: "기적 같은 결말의 버려진 강아지"

hashtags:
  - "#동물감동"
  - "#골든리트리버"
  - "#고슴도치"
  - "#동물가족"
  - "#shorts"
```

## 제목 작성 팁

### DO
- 감정적 단어 사용 (감동, 눈물, 따뜻한)
- 숫자 포함 ("1년 후", "5마리")
- 호기심 유발 ("...결말 충격")
- 괄호 활용 "(실화)", "(감동주의)"

### DON'T
- 너무 긴 제목
- 스포일러
- 과장된 낚시
- 부정적 표현
