# Taped Legs

> 배달기사 여성이 골목에서 뒷다리가 테이프로 묶인 채 기어가는 고양이를 발견 → 츄르로 경계를 풀고 → 병원에서 테이프 제거 + X-ray로 골절 확인 → 회복 후 가족이 되는 이야기

**총 길이:** 105초 (7개 장면)

---

## 캐릭터 레퍼런스

### 동물 캐릭터

> 회색 숏헤어 성묘 암컷. 노란-초록 둥근 눈.

| Scene | 물리적 상태                                   | 감정                      | 행동                                                    |
| ----- | --------------------------------------------- | ------------------------- | ------------------------------------------------------- |
| 1     | 뒷다리 테이프 여러 겹 감김, 마름, 탈수        | 공포, 고통                | 앞발로 콘크리트 짚으며 한 뼘씩 기어감, 뒷다리 질질 끌림 |
| 2     | 같은 상태, 가까이서 보임                      | 경계 → 먹는 데 집중 → 안심 | 킁킁거리며 다가옴 → 츄르 핥기 → 쓰다듬기 허용, 눈 반쯤 감음 |
| 3     | 테이프 감긴 채 자켓에 싸임                    | 겁먹음 → 체념             | 자켓에 감싸이자 움직임 멈춤, 눈만 두리번                |
| 4     | 테이프 제거됨, 뒷다리 부목+붕대, X-ray에 골절 | 피로 + 비적대적           | 진료대에 가만히 누움, 눈 반쯤 감김                      |
| 5     | 뒷다리 부목+붕대, 약간 살 붙음                | 경계 (공포→경계)          | 침대 밑 숨기, 몰래 먹기                                 |
| 6     | 붕대 해제, 뒷다리 털 재생, 건강               | 안정감, 신뢰              | 배 뒤집기, 몸 비비기                                    |
| 7     | 털 완전 재생, 건강 체중                       | 완전한 사랑               | 가슴 위에서 잠들기                                      |

### 인간 캐릭터

> 20대 후반 백인 여성. 갈색 포니테일. 갈색 배달 유니폼 (갈색 폴로셔츠, 카키 카고 바지, 갈색 워크부츠).

- Scene 1: 관찰자 시점 촬영 (목소리만 들림)
- Scene 2-4: 1인칭 POV (여성 손, 갈색 폴로셔츠 소매, 숙일 때 포니테일 보임)
- Scene 5: 그레이 후드티, 검정 레깅스 (집)
- Scene 6: 갈색 배달 유니폼 (출근)
- Scene 7: 흰 티셔츠, 회색 스웨트팬츠 (집)

## Scene 1: 기어가는 고양이 (Something Crawling) — HOOK

- **Duration:** 15s
- **Emotion:** 충격, 분노
- **Camera:** 관찰자 시점, 멀리서 디지털 줌, 단일 연속 샷
- **Lighting:** 늦은 저녁, 가로등 빛

**Caption:**

- EN: "Someone did this to her..."
- KR: "누군가 일부러 이렇게 한 거였다..."

### Sora2 Prompt

```
// Story: 전체: 배달기사 여성이 골목에서 뒷다리가 테이프로 묶인 채 기어가는 고양이를 발견 → 츄르로 경계를 풀고 → 병원에서 테이프 제거 + X-ray 골절 확인 → 회복 후 가족이 되는 이야기.
앞 장면: 없음 (첫 장면).
이 장면: 멀리서 골목 바닥을 느리게 기어가는 고양이를 발견. 줌인하면 뒷다리 두 개가 테이프로 여러 겹 단단히 감겨 있음. 누군가 의도적으로 한 것이 명백함.

주변인 관찰 시점 핸드폰 촬영. 한 위치에서 디지털 줌. 흔들리고 불안정한 아마추어 푸티지.

회색 숏헤어 성묘 암컷. 마르고 탈수. 노란-초록 눈. 뒷다리 두 개가 테이프로 여러 겹 빈틈없이 감겨 완전히 붙어 있음. 앞발로 콘크리트 바닥을 한 발씩 짚으며 몸을 앞으로 끌어당기고, 뒷다리는 바닥에 축 늘어져 질질 끌림.

단일 연속 샷 15초. 멀리서 골목 바닥을 느리게 기어가는 작은 형체. 앞발만 움직이고 뒷몸이 끌리는 이상한 움직임. 디지털 줌인하면 회색 고양이가 앞발로 바닥을 짚으며 한 뼘씩 기어감. 더 줌인하면 뒷다리가 테이프로 빈틈없이 감겨 있음 — 발끝부터 허벅지까지 촘촘하게 감긴 테이프. 자연적으로 불가능한, 누군가 일부러 감은 것이 명백한 모양.

```

**End Frame:** 서서 위에서 내려다보는 시점. 어두운 아스팔트 바닥 위 고양이가 앞발로 기어가며 멀어짐. 뒷다리에 감긴 테이프가 보임. 촬영자의 그림자가 바닥에 드리움. 가로등 빛.

**End Frame:** 쪼그리고 앉은 POV. 여자 손이 고양이 머리를 쓰다듬고 있음. 고양이 눈 반쯤 감김. 테이프 감긴 뒷다리가 옆으로 보임. 가로등 빛.

## Scene 4: 부러진 다리 (Broken Bones)

- **Emotion:** 충격(골절), 안도
- **Camera:** 1인칭 POV, 유리문 너머 촬영 + X-ray 클로즈업
- **Lighting:** 밝은 형광등 (병원)

**Caption:**

- EN: "Both back legs were broken under the tape"
- KR: "테이프 아래 두 다리 모두 부러져 있었다"

### Sora2 Prompt

```
(스타트 프레임: 밴 조수석에 놓인 자켓에 감싸인 고양이. 노란-초록 눈이 카메라를 올려다봄. 밴 실내등.) 에서 시작. 시작 즉시 다른 구도로 전환 — 동물병원 복도, 유리문 너머로 진료실이 보임.

// Story: 전체: 배달기사 여성이 골목에서 뒷다리가 테이프로 묶인 채 기어가는 고양이를 발견 → 츄르로 경계를 풀고 → 병원에서 테이프 제거 + X-ray 골절 확인 → 회복 후 가족이 되는 이야기.
앞 장면: 자켓으로 감싸 배달 밴에 태우고 동물병원으로 달려왔다.
이 장면: 유리문 너머로 수의사가 고양이를 처치하는 모습 (간접). X-ray 사진에 뒷다리 두 개 모두 골절이 보인다.

촬영자: 20대 후반 백인 여성. 갈색 포니테일. 자켓 없이 갈색 폴로셔츠. (1인칭 POV — 한 손, 소매 보임)

수의사: 30대 백인 남성. 흰 가운. 유리문 너머에서 고양이를 처치 중.

회색 숏헤어 성묘 암컷. 마름. 유리문 너머 진료대 위에 누움. 뒷다리에서 테이프 제거된 상태.

(0-1초) 즉시 컷 전환 — 동물병원 복도. 유리문 너머 진료실이 보임.
(1-5초) 1인칭 POV. 유리문 너머로 수의사의 뒷모습. 진료대 위 고양이를 처치 중. 디테일은 보이지 않음.
(5-10초) 컷 전환. 벽에 걸린 X-ray 라이트박스 클로즈업. 고양이 뒷다리 두 개의 뼈가 각각 골절된 것이 선명하게 보임.
(10-15초) 컷 전환. 진료대 위 고양이. 뒷다리에 부목과 붕대 감김. 고양이가 눈을 반쯤 감고 누워 있음.

No background music. 병원 장비 소리, 형광등 윙윙거림, 여자 숨소리, 고양이 가느다란 울음.
```

**End Frame:** 진료대 위 뒷다리에 부목과 붕대가 감긴 고양이. 눈을 반쯤 감고 누워 있음. 밝은 형광등.
