# Taped Legs

> 여성이 길에서 뒷다리가 테이프로 묶인 채 기어가는 고양이를 목격 → 다가가자 하악질하며 도망 → 츄르로 경계를 풀고 → 병원에서 X-ray 골절 확인 + 수술로 테이프 제거 → 집에서 골든리트리버의 사랑으로 경계를 풀고 가족이 되는 이야기

**총 길이:** 120초 (8개 장면)

---

## 캐릭터 레퍼런스

### 고양이

> 회색 숏헤어 성묘 암컷. 노란-초록 둥근 눈.

| Scene | 물리적 상태                                   | 감정                       | 행동                                                    |
| ----- | --------------------------------------------- | -------------------------- | ------------------------------------------------------- |
| 1     | 뒷다리 테이프 여러 겹 감김, 마름, 탈수        | 공포, 고통                 | 앞발로 콘크리트 짚으며 한 뼘씩 기어감, 뒷다리 질질 끌림 |
| 2     | 같은 상태, 가까이서 보임                      | 공포 → 적대적 경계         | 하악질, 앞발로 필사적으로 기어서 도망, 벽에 몰려 으르렁 |
| 3     | 같은 상태                                     | 경계 → 먹는 데 집중 → 안심 | 킁킁거리며 다가옴 → 츄르 핥기 → 머리 쓰다듬기 허용      |
| 4     | 테이프 제거됨, 뒷다리 부목+붕대, X-ray에 골절 | 피로 + 비적대적            | 진료대에 가만히 누움, 눈 반쯤 감김                      |

| 6     | 붕대 해제, 뒷다리 털 재생 중, 건강해짐        | 경계 → 수용 → 호기심       | 골든의 그루밍 받아들임, 나란히 밥 먹기, 코 킁킁         |
| 7     | 붕대 해제, 뒷다리 털 거의 재생, 건강해짐      | 소속감, 편안함              | 현관문 앞에서 골든과 나란히 앉아 여자를 기다림           |
| 8     | 털 완전 재생, 건강 체중                       | 완전한 안심, 사랑          | 골든 배 위에서 웅크려 잠듦                              |

### 골든리트리버

> 성체 골든리트리버. 금색 긴 털. 갈색 눈. 대형견. 온순하고 참을성 있음.

| Scene | 감정         | 행동                                                          |
| ----- | ------------ | ------------------------------------------------------------- |
| 5     | 호기심, 흥분 | 고양이에게 코 들이밀기, 꼬리 흔들기. 하악질에 뒤로 물러남     |
| 6     | 차분, 보호적 | 고양이 옆에 엎드려 기다림, 고양이 머리를 혀로 핥아줌 (그루밍) |
| 7     | 기대, 충성적 | 현관문 앞에 앉아 기다림, 고양이와 나란히                      |
| 8     | 편안, 보호적 | 소파에 늘어져 잠, 고양이가 배 위에 올라와도 가만히 있음       |

## Scene 1: 기어가는 고양이 (Something Crawling) — HOOK

- **Duration:** 15s
- **Emotion:** 충격, 분노
- **Camera:** 관찰자 시점, 길 건너에서 디지털 줌, 단일 연속 샷
- **Lighting:** 낮, 흐린 하늘, 자연광

**Caption:**

- EN: "Someone did this to her..."
- KR: "누군가 일부러 이렇게 한 거였다..."

### Sora2 Prompt

```
// Story: 전체: 여성이 길에서 뒷다리가 테이프로 묶인 채 기어가는 고양이를 목격 → 다가가자 하악질하며 도망 → 츄르로 경계를 풀고 → 병원에서 X-ray 골절 확인 + 수술로 테이프 제거 → 집에서 골든리트리버의 사랑으로 가족이 되는 이야기.
앞 장면: 없음 (첫 장면).
이 장면: 길 건너편 인도에서 앞발만으로 기어가는 고양이를 목격. 디지털 줌인하면 뒷다리에 테이프가 감겨 있음. 고양이가 골목 입구로 기어 들어감.

주변인 관찰 시점 핸드폰 촬영. 길 건너에서 디지털 줌. 흔들리고 불안정한 아마추어 푸티지.

미국 포틀랜드 주택가 도로. 낮. 흐린 하늘. 왕복 2차선 도로. 건너편 인도와 건물 사이 골목 입구.

촬영자: 20대 후반 백인 여성. 갈색 포니테일. 베이지 자켓, 흰 티셔츠, 청바지. (관찰 시점 — 목소리만 들림)

회색 숏헤어 성묘 암컷. 마르고 탈수. 노란-초록 눈. 뒷다리 두 개가 테이프로 여러 겹 빈틈없이 감겨 완전히 붙어 있음. 앞발로 인도 바닥을 한 발씩 짚으며 몸을 앞으로 끌어당기고, 뒷다리는 바닥에 질질 끌림.

단일 연속 샷 15초. 길 건너 인도 위에 작은 형체가 느리게 움직임. 앞발만 움직이고 뒷몸이 끌리는 이상한 움직임. 디지털 줌인하면 회색 고양이가 앞발로 한 뼘씩 기어감. 더 줌인하면 뒷다리에 테이프가 촘촘하게 감겨 있음 — 발끝부터 허벅지까지 감긴 테이프. 자연적으로 불가능한, 누군가 일부러 감은 것이 명백한 모양. 고양이가 건물 사이 좁은 골목 입구로 기어 들어감.

No background music. 먼 차 소리, 고양이 뒷다리 끌리는 소리, 여자 숨 멈추는 소리, 여자가 놀라서 내는 작은 소리.
```

**End Frame:** 디지털 줌으로 본 건너편. 고양이가 건물 사이 좁은 골목 입구로 기어 들어가는 뒷모습. 흐린 낮. 테이프 감긴 뒷다리가 끌림.

- **Emotion:** 안쓰러움, 긴장
- **Camera:** 1인칭 POV, 골목 진입 → 접근 시도
- **Lighting:** 낮, 골목 안 그늘

**Caption:**

- EN: "She hissed and tried to run... but she couldn't"

```
// Story: 전체: 여성이 길에서 뒷다리가 테이프로 묶인 채 기어가는 고양이를 목격 → 다가가자 하악질하며 도망 → 츄르로 경계를 풀고 → 병원에서 X-ray 골절 확인 + 수술로 테이프 제거 → 집에서 골든리트리버의 사랑으로 가족이 되는 이야기.

(1-5초) 골목 안쪽으로 걸으며 둘러봄. 쓰레기통 뒤에서 고양이 발견. 천천히 다가감.
(5-10초) 여자가 1미터까지 다가가자 고양이가 하악질. 앞발로 필사적으로 바닥을 짚으며 기어서 도망. 뒷다리가 바닥에 끌림. 도망치지 못함.
(10-15초) 서서 내려다보는 시점. 벽돌 벽 옆 골목 바닥에서 고양이가 앞발로 기어감. 뒷다리 테이프가 끌림. 여자가 멈춰 서서 내려다봄.

No background music. 고양이 하악질, 고양이 으르렁거림, 앞발이 콘크리트 긁는 소리, 뒷다리 끌리는 소리, 여자가 조용히 말하는 소리.
```

**End Frame:** 서서 위에서 내려다보는 시점. 어두운 골목 콘크리트 바닥. 벽돌 벽 옆에서 고양이가 앞발로 기어감. 뒷다리에 테이프가 감겨 끌림.

## Scene 4: 부러진 다리 (Broken Bones)

- EN: "Both back legs were broken under the tape"

