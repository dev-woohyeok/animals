# 울타리에 끼인 백조를 구했더니 온 가족을 데려왔다

## 스토리

### 시놉시스

겨울 아침, 출근길에 보도 옆 철제 울타리에 몸이 끼어 빠지지 못하는 백조를 발견한다. 울타리를 벌려 구출하고 차에 태워 집으로 데려온다. 수건으로 감싸 돌보며 먹이를 주자 백조가 서서히 마음을 열고, 남자를 어디든 따라다니며 목을 감아 애정을 표현한다. 봄이 되어 호수로 방류하자 백조가 뒤를 돌아보다 헤엄쳐 가고, 물 위에서 짝을 만난다. 여름, 백조가 짝과 함께 남자 집 뒷마당에 돌아와 둥지를 틀고 새끼를 낳는다. 가을, 자란 새끼 백조들이 현관 앞까지 와서 밥을 먹는다.

### 감정 곡선 (U-Curve)

```
놀라움/경계(40) → 유머/당황(55) → 따뜻함/신뢰(80) → 가족애(95) → 이별/그리움(30) → 재회+가족/감동(100)
```

### 5막 구조

1. **도입**: 겨울 아침, 보도 옆 울타리에 백조가 끼어 있음. 놀라움.
2. **전개**: 구출 후 집에서 돌봄. 처음엔 경계하다 서서히 유대 형성. 무릎에 목을 올림.
3. **전환**: 백조가 남자를 따라다님. 산책, 집 안, 소파. 목을 감아 애정 표현. 가족.
4. **위기**: 봄, 호수에서 방류. 백조가 뒤돌아보다 헤엄쳐 감. 짝을 만남. 이별.
5. **결말**: 여름~가을, 백조가 짝과 새끼들을 데리고 뒷마당에 돌아옴. 현관까지 찾아오는 가족.

## 캐릭터 설정

### 촬영자 (1인칭 POV)

- 30대 중반 백인 남성
- 짧은 갈색 머리, 짧은 수염
- 겨울/야외: 노란 패딩 재킷, 청바지, 검은 비니
- 실내: 흰색 스웻셔츠, 회색 스웻팬츠
- 봄/야외: 회색 후드집업, 검은 바지
- 1인칭 POV (손, 소매 보임)

### 백조 (Mute Swan)

- 암컷 성체 뮤트 스완
- 흰 깃털, 주황-검정 부리 (주황 윗부분 + 검정 코브 돌기)
- 긴 S자형 목, 큰 몸체
- 약 10kg, 날개 펼치면 약 2m
- 검은 물갈퀴 발

### 새끼 백조 (Cygnets)

- 5마리
- 회색빛 솜털, 짧은 목
- 검은 부리, 검은 물갈퀴 발
- 작고 둥근 몸
