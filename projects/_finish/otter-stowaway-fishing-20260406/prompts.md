```
// Story: 전체: 알래스카 게잡이 어부가 그물에 걸린 아기 해달 구조 → 놓아줬지만 해달이 매번 보트에 올라타 → 낚시 파트너가 됨 → 야생 가족과 재회.
앞 장면: 없음 (첫 장면).

아기 해달 한 마리 (암컷). 약 2kg. 작고 마른 체구. 젖은 짙은 갈색 털. 크고 둥근 검은 눈. 그물줄이 몸에 감겨 있음. 입을 벌리고 울고 있음.

No background music. 윈치 돌아가는 소리, 바다 파도 소리, 아기 해달 울음소리, 거친 숨소리.
```

```
// Story: 전체: 알래스카 게잡이 어부가 그물에 걸린 아기 해달 구조 → 놓아줬지만 해달이 매번 보트에 올라타 → 낚시 파트너가 됨 → 야생 가족과 재회.
```

```
이 장면: 몇 주 뒤 해안 산책 중 바위 위에서 해달 가족과 함께 있는 해달을 발견. 해달이 어부를 알아보고 다가왔다 가족에게 돌아감 — 감동적 이별.

해달 3마리. 바위 위에 2마리, 물가에 1마리. 그중 한 마리(암컷)가 구조했던 해달 — 약 3.5kg. 성체에 가까운 건강한 체구. 윤기 나는 두꺼운 짙은 갈색 털. 크고 둥근 검은 눈.
```
