# Mother's Plea

> 폭우 속 엄마 고양이가 행인들에게 무시당하다 남자에게 다가와 바지를 물고 끌어감 → 따라가니 비에 젖은 아기 고양이가 떨고 있음 → 병원에서 램프 아래 치료 + 우유 먹이기 → 집에 데려와 침대에서 엄마+아기+남자 함께 잠드는 가족이 됨

**총 길이:** 60초 (4개 장면)

---

## 캐릭터 레퍼런스

### 엄마 고양이

> 칼리코 얼룩 성묘 암컷. 중형. 주황+검정+흰색 얼룩 패턴. 초록색 둥근 눈.

| Scene | 물리적 상태 | 감정 | 행동 |
| ----- | ----------- | ---- | ---- |
| 1 | 비에 완전히 젖어 납작하게 붙은 털, 마르고 지침 | 절박, 간절함 | 행인에게 다가가 무시당함, 남자 바지를 물고 당김 |
| 2 | 비에 젖음, 에너지 소모 | 급박, 안도 시작 | 앞서 달려가며 뒤돌아봄, 아기 곁으로 안내 |
| 3 | 수건으로 감싸짐, 털 아직 젖었지만 정돈됨 | 진정, 보호 본능 | 아기 옆에 누워 핥아줌 |
| 4 | 깨끗하고 건강한 윤기 나는 털 | 완전한 안심, 사랑 | 남자 가슴 위에 웅크려 잠듦 |

### 아기 고양이

> 칼리코 얼룩 아기 고양이 암컷. 손바닥 크기. 생후 2-3주. 주황+흰색 미완성 얼룩. 파란 눈 (신생아).

| Scene | 물리적 상태 | 감정 | 행동 |
| ----- | ----------- | ---- | ---- |
| 2 | 비에 젖어 떨고 있음, 배수관 아래 판지 위 | 공포, 추위 | 웅크려 떨고 있음 |
| 3 | 수건 위, 램프 아래 체온 회복 중 | 배고픔 → 안정 | 주사기 우유 핥음, 엄마 옆에서 누움 |
| 4 | 약간 자람, 건강해짐 | 편안, 안심 | 엄마 배 위에 올라가 웅크려 잠듦 |

### 인간 캐릭터

> 30대 초반 백인 남자. 짧은 갈색 머리. 검은 후디, 청바지.

- Scene 1: 1인칭 POV (검은 후디 소매, 손 보임)
- Scene 2: 1인칭 POV (검은 후디 소매, 달리면서 촬영)
- Scene 3: 1인칭 POV (검은 후디 소매, 비에 젖은 상태)
- Scene 4: 1인칭 POV (회색 티셔츠, 침대에 누워서 촬영)
