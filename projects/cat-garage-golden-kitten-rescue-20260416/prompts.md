## 캐릭터 설정

### 동물 캐릭터
- **새끼고양이**: 암컷. 생후 약 4-5주. 손바닥 크기. 순백색 짧은 털. 큰 분홍 귀. 둥근 갈색 눈. 분홍 코.
- **골든 리트리버**: 수컷. 성체(약 30kg). 금색 긴 털. 큰 갈색 눈. 검은 코.
- **성장한 고양이** (Scene 6): 암컷. 성체(약 4kg). 윤기나는 순백색 털. 큰 분홍 귀. 둥근 갈색 눈. 분홍 코.

### 인간 캐릭터
- **촬영자**: 20대 후반 백인 여성. 밝은 갈색 긴 머리 포니테일. 회색 티셔츠, 검은 레깅스. (1인칭 POV — 손, 옷소매 보임)

### 장소
- 미국 오레곤주 포틀랜드 교외 주택 (이사 직후)

## Scene 1: 골든이 자꾸 발을 끈다

```
// Story: 전체: 이사 중 골든이 자꾸 발을 끌어 따라가보니 차고 구석에 버려진 새끼고양이 발견 → 겁먹은 고양이가 골든 품에서 처음 안심 → 가족이 됨.
// 앞 장면: 없음 (첫 장면).
// 이 장면: 이사 짐 옮기는데 골든이 자꾸 발목 바지단을 물어 끔. 귀찮아서 밀어내도 또 끎. 결국 따라가보니 차고 구석에 하얀 새끼고양이가 웅크리고 울고 있음 — 놀라움.

1인칭 POV 핸드폰 영상. 흔들리고 불안정한 아마추어 푸티지.

미국 오레곤주 포틀랜드 교외 주택. 차고 내부 + 입구. 낮. 이삿짐 상자들이 일부 쌓여 있고 아직 옮기는 중. 차고 형광등 + 열린 문으로 자연광. 차고 입구 밖에 이삿짐 트럭 뒷부분 살짝 보임.

골든 리트리버 한 마리. 수컷. 성체(약 30kg). 금색 긴 털. 큰 갈색 눈. 검은 코. 흥분해서 꼬리 흔들며 촬영자의 발목 위 청바지 바지단 끝자락(ankle hem)을 입으로 물어 끎. 머리 높이 20-30cm. 허벅지/사타구니 아닌 발목 부분만.

하얀 새끼고양이 한 마리. 암컷. 생후 약 4-5주. 손바닥 크기. 순백색 짧은 털이 먼지로 더러워져 있음. 큰 분홍 귀. 둥근 갈색 눈. 분홍 코. 상자 구석에 웅크리고 있음.

(0-1초) 참조 이미지 프레임.
— 1초에 빠른 화면 전환 —
(1-15초) 촬영자가 이삿짐 상자를 들고 차고로 옮기는 중. 골든이 촬영자의 발목 위 청바지 바지단 끝자락을 입으로 물고 차고 안쪽으로 끎. 촬영자가 한 손으로 밀어내지만 골든이 다시 물고 끎. 카메라가 흔들리며 아래로 향함. 결국 상자를 내려놓고 골든을 따라감. 골든이 차고 안쪽 구석을 향해 킁킁거리며 이동. 쌓인 상자 뒤에 웅크린 하얀 새끼고양이가 보임. 디지털 줌인. 새끼고양이가 떨면서 카메라를 올려다봄.

No background music. 골든 킁킁 소리, 바지단 끄는 소리, 새끼고양이 울음소리, 이삿짐 상자 내려놓는 둔탁한 소리, 여성 숨소리, 차고 반향음.
```

## Scene 6: 가족이 된 둘

```
// Story: 전체: 이사 중 골든이 자꾸 발을 끌어 따라가보니 차고 구석에 버려진 새끼고양이 발견 → 겁먹은 고양이가 골든 품에서 처음 안심 → 가족이 됨.
// 앞 장면: 며칠 후 새끼고양이가 골든을 그림자처럼 따라다니며 완전히 신뢰하게 됐다.
// 이 장면: 시간 경과 — 성장한 하얀 고양이가 골든 위에 올라가 장난치고, 소파에서 골든 품에 파고들어 잠듦 — 차고에서 떨던 아기가 이제 가족의 품에. 감동의 결말.

홈비디오 스타일 핸드폰 영상. 흔들리고 불안정한 아마추어 푸티지.

미국 오레곤주 포틀랜드 교외 주택 내부. 거실. 낮. 큰 창문으로 오후 햇살. 베이지색 소파. 나무 마루바닥.

하얀 고양이 한 마리. 암컷. 성체(약 4kg). 윤기나는 순백색 털. 큰 분홍 귀. 둥근 갈색 눈. 분홍 코. 건강한 체중.

골든 리트리버 한 마리. 수컷. 성체(약 30kg). 건강하고 윤기나는 금색 긴 털. 큰 갈색 눈. 검은 코. 편안한 표정.

20대 후반 백인 여성. 밝은 갈색 긴 머리. 크림색 스웨터. (홈비디오 촬영 — 손, 무릎만 보임)

(0-1초) 참조 이미지 프레임.
— 1초에 빠른 화면 전환 —
(1-5초) 거실 마루바닥. 성장한 하얀 고양이가 골든 등 위에 올라가 앉음. 골든이 가만히 있으며 꼬리만 흔듦.
— 자연스러운 화면 전환 —
(5-10초) 베이지색 소파. 골든이 누워있고 하얀 고양이가 골든 앞발 사이로 파고들어 웅크림. 골든이 턱을 고양이 위에 올려놓음.
— 자연스러운 화면 전환 —
(10-15초) 클로즈업. 창문으로 오후 햇살이 들어옴. 골든과 하얀 고양이가 얼굴을 맞대고 잠들어 있음. 고양이 가르랑 소리.

No background music. 고양이 가르랑 소리, 골든 코고는 소리, 새소리, 바깥 바람 소리.
```
