```yaml

불꽃: 나무 사이로 주황-빨간 불꽃 가시
재/불씨: 공중에 눈처럼 떠다니는 재와 불씨
소리: 불 타는 굉음 (roaring), 나무 타닥거림 (crackling), 가끔 나무 쓰러짐
```

### 촬영자 (등장인물)

```yaml
성별: 남성 (30대)
인종: 백인, 그을린 피부
복장: 회색 후드집업, 청바지, 하이킹 부츠
손: 남성의 손, 약간 먼지/재 묻음
목소리: 북미 영어 억양, 낮은 톤, 긴박할 때 거칠어짐
호흡: 연기로 인한 기침 섞인 거친 숨
```

### 엄마 라쿤

```yaml
종: 북미 라쿤 (Procyon lotor)
크기: 중형견 크기, 체중 약 8-10kg
털색: 회갈색 (grayish-brown), 등은 더 어둡고 배는 연함
얼굴: 검은색 마스크 무늬 (눈 주위), 흰색 눈썹과 뺨
꼬리: 굵고 푹신한 줄무늬 꼬리 (5-7개 검은 줄)
상태: 탈진 → 회복 → 보호적/재촉하는, 눈에 지능적인 빛
```

### 아기 라쿤

```yaml
마릿수: 4마리
나이: 약 8-10주 (눈 뜨고 움직임 가능, 하지만 작음)
크기: 손바닥보다 약간 큼, 각 300-400g
털: 엄마와 같은 패턴, 더 푹신하고 부드러움
행동: 서로 붙어있음, 무서우면 떨고 울음
```
