# Hooks Library (후킹 라이브러리)

> 90초 쇼츠에서 20초마다 시청자를 붙잡는 후킹 기법 모음

## Overview

```
시청 지속시간 문제:
──────╮
      ╰──────────────  66%에서 이탈

해결책 - 20초 후킹:
──────●────●────●────●────●
     20s   40s  60s  80s  90s
      ↑     ↑    ↑    ↑    ↑
     B후킹 C후킹 D후킹 E후킹 엔딩
```

## 5단계 후킹 시스템

| 시간 | 코드 | 이름 | 목적 | 감정 |
|------|------|------|------|------|
| 0-20초 | A | 오프닝 | "이게 뭐지?" | 호기심 |
| 20-40초 | B | 전개 | "설마...?" | 기대+불안 |
| 40-60초 | C | 클라이맥스1 | "와!" | 놀라움 |
| 60-80초 | D | 클라이맥스2 | "진짜?" | 감동+긴장 |
| 80-90초 | E | 완결 | "결국..." | 안도+여운 |

- [climax1_hooks.md](./climax1_hooks.md) - C단계 (40-60초)

## 후킹 강도 원칙

```
강도
 5 │           ★ C        ★ E
 4 │     ★ B     ╲      ╱
 3 │ ★ A          ★ D ╱
 2 │
 1 │
   └─────────────────────────
     0   20   40   60   80  90초
```

### 핵심 규칙:
1. **C (40초)가 가장 강력** - 최대 긴장/놀라움
2. **D (60초)에서 내리지 말것** - 이탈 구간, 새 긴장 필요
3. **E (80초)로 다시 상승** - 감동으로 마무리

## 후킹 체크리스트

### 필수 요소
- [ ] 각 20초 구간에 명확한 후킹 포인트
- [ ] C 클라이맥스가 가장 강렬
- [ ] D 구간에서 새로운 긴장 요소
- [ ] E에서 감정적 해소

### 금지 요소
- [ ] 20초 이상 평화로운 장면 연속
- [ ] 40-60초 구간에서 긴장 해소
- [ ] 예측 가능한 전개
- [ ] 감정 곡선 급락

## Quick Reference

### 오프닝 (A) 베스트
1. 이상한 발견/소리
2. 위기 상황 직접 시작
3. 반전 예고 ("3개월 후...")
4. 행동 중간 시작

### 전개 (B) 베스트
1. 예상 뒤집기
2. 추가 발견
3. 동물의 예상 못한 반응
4. 상황 악화

### 클라이맥스1 (C) 베스트
1. 대반전
2. 감정 폭발
3. 위기의 절정
4. 숨겨진 진실

### 클라이맥스2 (D) 베스트
1. 2차 위기
2. 역할 반전
3. 신기한 행동
4. 마지막 선택

### 완결 (E) 베스트
1. 완전한 신뢰
2. 시간 점프
3. 감사 표현
4. 미래 암시

## 사용법

```yaml
# 스토리 설계 시
story:
  hook_A: "{{OPENING_HOOK}}"
  hook_B: "{{DEVELOPMENT_HOOK}}"
  hook_C: "{{CLIMAX1_HOOK}}"
  hook_D: "{{CLIMAX2_HOOK}}"
  hook_E: "{{ENDING_HOOK}}"

# 각 후킹 파일에서 적합한 유형 선택
```
