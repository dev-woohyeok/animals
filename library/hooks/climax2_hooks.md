# Climax 2 Hooks (D단계: 60-80초)

> 이탈 방지의 핵심 구간, C 이후 긴장을 유지하며 감동으로 전환

## 목표

```
"진짜?" / "어떻게 되지?" → 긴장 유지 → 감동 준비
```

## ⚠️ 중요: 66% 이탈 방지 구간

```
기존 문제:
C(100) → D(50) ← 여기서 급락하면 이탈

해결책:
C(100) → D(85) ← 새로운 긴장으로 유지
```

## Hook Types

### D1. 2차 위기 (Secondary Crisis)
```yaml
type: secondary_crisis
strength: ★★★★★
description: 해결된 줄 알았는데 새로운 문제

examples:
  - "다른 위험 등장"
  - "날씨 악화"
  - "상태가 다시 안 좋아짐"
  - "새로운 장애물"

intensity: 85
visual:
  - 새로운 위협 요소
  - 안심 후 긴장
  - 환경 변화

why_important:
  - C 이후 이완 방지
  - 새로운 관심 유발
```

### D2. 탈출/해결 과정 (Escape Process)
```yaml
type: escape_process
strength: ★★★★☆
description: 위기에서 빠져나가는 과정

examples:
  - "동물 안고 후퇴"
  - "물살과 싸우며 수영"
  - "연기 속에서 탈출"
  - "포식자 피해 이동"

intensity: 80
visual:
  - 액션 장면
  - 움직임
  - 진행 과정

prompt_style:
  - 과정의 어려움
  - 끝이 보이지 않음
```

### D3. 기다림의 긴장 (Waiting Tension)
```yaml
type: waiting_tension
strength: ★★★★☆
description: 결과를 기다리는 서스펜스

examples:
  - "10분... 20분... 움직임 없음"
  - "눈을 뜨려나?"
  - "살았나? 숨 쉬나?"
  - "반응이 올까?"

intensity: 80
visual:
  - 시간 경과 표현
  - 초조한 기다림
  - 변화 없음 → 작은 변화

prompt_style:
  - 시간 마커
  - 포기 직전
  - 작은 희망
```

### D4. 마지막 선택 (Final Choice)
```yaml
type: final_choice
strength: ★★★★☆
description: 결정적인 선택의 순간

examples:
  - "야생 vs 함께"
  - "떠날까 남을까"
  - "마지막 한 마리"
  - "포기할까 계속할까"

intensity: 80
visual:
  - 갈림길 순간
  - 결정의 무게
  - 선택 후 행동

prompt_style:
  - 망설임 표현
  - 결심 순간
```

### D5. 신뢰 테스트 (Trust Test)
```yaml
type: trust_test
strength: ★★★★☆
description: 동물이 진정으로 마음 여는 순간

examples:
  - "처음 만지게 해줌"
  - "자발적으로 다가옴"
  - "품에 안김"
  - "따라오기로 선택"

intensity: 85
visual:
  - 거리 좁혀짐
  - 접촉 순간
  - 동물의 선택

prompt_style:
  - 천천히 다가옴
  - 결정적 접촉
```

### D6. 예상 못한 행동 (Unexpected Action)
```yaml
type: unexpected_action
strength: ★★★★★
description: 동물이 놀라운 행동을 함

examples:
  - "갑자기 큰 소리를 냄"
  - "특정 방향으로 이끔"
  - "무언가를 가져옴"
  - "사람을 보호하는 행동"

intensity: 90
visual:
  - 주도적 행동
  - 의도적 움직임
  - 놀라운 결과

prompt_style:
  - 동물 주체
  - 인간 반응
```

### D7. 변화의 순간 (Transformation Moment)
```yaml
type: transformation_moment
strength: ★★★★☆
description: 상태/관계의 변화가 보이는 순간

examples:
  - "처음으로 밥 먹음"
  - "처음으로 걸음"
  - "경계가 풀림"
  - "회복 신호"

intensity: 80
visual:
  - 변화 전후
  - 이정표 달성
  - 희망 신호

prompt_style:
  - 작은 변화
  - 큰 의미
```

## Best Practices

### 60-80초 구조
```
60-65초: C의 여파 / 전환
65-70초: 새로운 긴장 or 과정
70-75초: 클라이맥스2
75-80초: E단계로 전환
```

### D 후킹 필수 요소
```
✅ C보다 약간 낮지만 여전히 높은 긴장
✅ 새로운 관심 요소
✅ 감동으로 전환 준비
✅ 완전한 해결 직전
✅ E에서 터질 감정 빌드업
```

## Prompt Examples

### D1 - 2차 위기
```
Carrying the fox, slowly backing away.
Wolves following, distance getting shorter.
Heart pounding, can't run, can't fight.
Suddenly the fox lets out a loud cry.
No background music, wolf growling, fox crying out, panicked breathing.
```

### D3 - 기다림의 긴장
```
Inside the warm car, heater on maximum.
The tiny fox wrapped in jacket, not moving.
10 minutes pass... nothing.
20 minutes... still nothing.
About to lose hope... tiny movement under the fabric.
No background music, car heater sound, soft gasp.
```

### D5 - 신뢰 테스트
```
The fox stops crying.
Slowly looks up at the person.
For the first time, walks closer instead of away.
Hesitates, then presses its head against the hand.
No background music, soft breathing, first trusting whimper.
```

## 안티 패턴 (피해야 할 것)

```
❌ C 이후 급격한 이완
❌ 설명/대화로 채우기
❌ 긴장감 없는 대기
❌ 감동 없는 진행
❌ E보다 강한 클라이맥스
```

## E단계 연결 가이드

| D 유형 | → E 추천 전개 |
|--------|--------------|
| 2차 위기 | 최종 해결 |
| 탈출 과정 | 안전 도착 |
| 기다림 긴장 | 회복 확인 |
| 마지막 선택 | 선택 결과 |
| 신뢰 테스트 | 완전한 신뢰 |
| 예상 못한 행동 | 행동의 결과 |
| 변화 순간 | 완전한 변화 |
