# Ending Hooks (E단계: 80-90초)

> 감동의 마무리와 구독/팔로우 유도를 위한 여운 있는 엔딩

## 목표

```
"결국..." → 감정 해소 → "또 보고싶다" → 구독
```

## E단계의 역할

```
강도 흐름:
D(85) → E(90) → 엔딩(80)
          ↑
    마지막 감동 피크

감정 흐름:
긴장 → 안도 → 감동 → 여운
```

## Hook Types

### E1. 완전한 신뢰 (Complete Trust)
```yaml
type: complete_trust
strength: ★★★★★
description: 동물이 100% 마음을 연 순간

examples:
  - "품에 안겨 잠듦"
  - "배를 보여줌"
  - "손을 핥아줌"
  - "따라오기로 선택"

intensity: 90
visual:
  - 완전한 이완
  - 친밀한 접촉
  - 평화로운 순간

emotion: 감동, 따뜻함
```

### E2. 시간 점프 (Time Skip)
```yaml
type: time_skip
strength: ★★★★★
description: 미래 모습 공개

examples:
  - "6개월 후..."
  - "1년 후, 건강하게 뛰어놂"
  - "지금은 가족이 됐다"
  - "새끼와 함께 돌아왔다"

intensity: 90
visual:
  - 시간 텍스트
  - 변화된 모습
  - 행복한 일상

emotion: 희망, 보람
```

### E3. 감사 표현 (Gratitude Display)
```yaml
type: gratitude_display
strength: ★★★★☆
description: 동물이 고마움 표시

examples:
  - "뒤돌아보며 잠시 멈춤"
  - "마지막으로 손 핥아줌"
  - "선물을 가져옴"
  - "매일 찾아오기 시작"

intensity: 85
visual:
  - 동물의 행동
  - 눈 맞춤
  - 작별/연결

emotion: 감동, 연결
```

### E4. 새 가족 (New Family)
```yaml
type: new_family
strength: ★★★★★
description: 가족으로 받아들임

examples:
  - "집에 가자"
  - "이름을 지어줌"
  - "함께 잠듦"
  - "일상을 공유"

intensity: 90
visual:
  - 함께하는 모습
  - 가정 환경
  - 새로운 시작

emotion: 사랑, 행복
```

### E5. 야생 복귀 (Return to Wild)
```yaml
type: return_to_wild
strength: ★★★★☆
description: 건강해져서 야생으로

examples:
  - "숲으로 돌아감"
  - "뒤돌아보고 사라짐"
  - "가끔 찾아옴"
  - "자유롭게 뛰어놂"

intensity: 85
visual:
  - 자연으로 복귀
  - 마지막 눈 맞춤
  - 달려가는 뒷모습

emotion: 뿌듯함, 씁쓸한 기쁨
```

### E6. 재회 (Reunion)
```yaml
type: reunion
strength: ★★★★★
description: 다시 만남

examples:
  - "몇 달 후 다시 나타남"
  - "날 기억한다!"
  - "새끼와 함께 왔다"
  - "매일 찾아오는 친구"

intensity: 95
visual:
  - 반가운 재회
  - 기억하는 행동
  - 새로운 소식

emotion: 감동, 기쁨
```

### E7. 시리즈 암시 (Series Hint)
```yaml
type: series_hint
strength: ★★★★☆
description: 다음 이야기 궁금증

examples:
  - "또 다른 소리가..."
  - "다음 날도 찾아왔다"
  - "새로운 동물 등장"
  - "계속될 이야기"

intensity: 80
visual:
  - 다음 편 힌트
  - 새로운 시작 암시
  - 궁금증 유발

emotion: 기대감, 궁금함
```

## Best Practices

### 80-90초 구조
```
80-83초: D 해결 / 안도
83-87초: 감동 피크
87-90초: 여운 / 엔딩
(90초 이후: 구독 CTA)
```

### E 후킹 필수 요소
```
✅ 감정적 카타르시스
✅ 완전한 해결
✅ 여운 남기기
✅ 구독 욕구 자극
✅ 다음 편 기대감
```

## Prompt Examples

### E1 - 완전한 신뢰
```
Back in the warm car, the fox finally relaxes.
Eyes slowly close, tiny body goes limp in arms.
First time sleeping peacefully since rescue.
Complete trust, complete safety.
No background music, soft breathing, car heater humming.
```

### E2 - 시간 점프
```
Text appears: "6 months later"
Same fox, now healthy and fluffy.
Running happily in the backyard.
Comes running when called, tail wagging.
No background music, happy yipping, laughter.
```

### E4 - 새 가족
```
Walking toward the car, fox in arms.
Opens the door, places fox gently inside.
Looks at the fox, makes a decision.
"Let's go home."
No background music, car door closing, engine starting.
```

### E5 - 야생 복귀
```
At the edge of the forest, fully recovered.
The fox looks back one last time.
A long moment of eye contact.
Then turns and runs into the trees.
No background music, soft forest sounds, running footsteps fading.
```

## 엔딩 + 구독 CTA 연결

```
감동 엔딩
    ↓
여운 2-3초
    ↓
"Part 2 coming soon" or "Follow for more"
    ↓
다음 편 기대
```

## 완성된 5단계 후킹 체크리스트

```
[ ] A (0-20초): 오프닝 후킹
[ ] B (20-40초): 전개 후킹
[ ] C (40-60초): 클라이맥스1 후킹 (최강)
[ ] D (60-80초): 클라이맥스2 후킹 (이탈 방지)
[ ] E (80-90초): 엔딩 후킹 (감동 + 구독)
```
