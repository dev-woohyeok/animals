# Climax 1 Hooks (C단계: 40-60초)

> 영상의 최고 긴장점, 가장 강력한 후킹이 필요한 구간

## 목표

```
"와!" / "헐!" → 최대 감정 반응 → 계속 봐야 함
```

## ⚠️ 중요: 이 구간이 가장 강력해야 함

```
강도 차트:
A(60) → B(75) → C(100) → D(85) → E(90)
                  ↑
            여기가 최고점
```

## Hook Types

### C1. 대반전 (Major Twist)
```yaml
type: major_twist
strength: ★★★★★
description: 상황이 완전히 뒤집힘

examples:
  - "야생동물이 사실 누군가 키우던 애"
  - "죽은 줄 알았는데 살아있음"
  - "적인 줄 알았는데 구해주려 한 것"
  - "한 마리인 줄 알았는데 새끼들이 있었다"

intensity: 100
visual:
  - 충격적인 발견
  - 상황 재해석
  - 관점 전환

prompt_style:
  - 갑작스러운 발견
  - 이전 정보와 연결
```

### C2. 감정 폭발 (Emotional Peak)
```yaml
type: emotional_peak
strength: ★★★★★
description: 강렬한 감정 순간

examples:
  - "동물이 처음 꼬리 흔듦"
  - "처음으로 울음 멈추고 안김"
  - "사람 손을 핥음"
  - "눈을 뜸"

intensity: 95
visual:
  - 동물 감정 표현
  - 교감 순간
  - 클로즈업

prompt_style:
  - 동물 행동 묘사
  - 감정적 반응
```

### C3. 위기의 절정 (Peak Danger)
```yaml
type: peak_danger
strength: ★★★★★
description: 가장 긴장되는 순간

examples:
  - "포식자가 바로 앞에"
  - "물이 목까지 참"
  - "불길이 코앞에"
  - "거의 떨어뜨릴 뻔"

intensity: 100
visual:
  - 위험 요소 최대 근접
  - 탈출구 없어 보임
  - 절체절명

prompt_style:
  - 위험 구체적 묘사
  - 긴박한 상황
```

### C4. 신기한 행동 (Amazing Behavior)
```yaml
type: amazing_behavior
strength: ★★★★☆
description: 놀라운 동물 행동

examples:
  - "새끼를 데려옴"
  - "길을 안내함"
  - "위험을 알려줌"
  - "사람을 보호함"

intensity: 90
visual:
  - 예상 못한 행동
  - 지능적 반응
  - 의도적 행동

prompt_style:
  - 동물 주도적 행동
  - 놀라움 표현
```

### C5. 숨겨진 진실 (Hidden Truth)
```yaml
type: hidden_truth
strength: ★★★★★
description: 몰랐던 사실 공개

examples:
  - "임신 중이었다"
  - "과거 트라우마 발견"
  - "새끼들이 숨어있었다"
  - "오래 굶은 상태였다"

intensity: 95
visual:
  - 새로운 발견
  - 이전 행동 이해
  - 감정적 충격

prompt_style:
  - 발견 순간
  - 상황 재해석
```

### C6. 연쇄 발견 (Chain Discovery)
```yaml
type: chain_discovery
strength: ★★★★☆
description: 한 발견이 다른 발견으로

examples:
  - "둥지 발견 → 알 발견 → 부화 직전"
  - "동물 구조 → 따라가니 → 더 있음"
  - "상처 치료 → 다른 상처 발견 → 심각"

intensity: 90
visual:
  - 연속적 발견
  - 스테이크 상승
  - 복잡도 증가

prompt_style:
  - 단계적 발견
  - 긴장 누적
```

### C7. 역할 반전 (Role Reversal)
```yaml
type: role_reversal
strength: ★★★★★
description: 구하는 입장이 뒤바뀜

examples:
  - "동물이 오히려 사람을 구함"
  - "도움받던 동물이 위험 경고"
  - "쫓기던 동물이 보호해줌"

intensity: 100
visual:
  - 입장 전환
  - 동물의 보호 행동
  - 예상 뒤집기

prompt_style:
  - 반전 순간
  - 새로운 관계
```

## Best Practices

### 40-60초 구조
```
40-45초: 빌드업 (긴장 최고조)
45-50초: 폭발 (후킹 포인트)
50-55초: 반응 (충격/감동)
55-60초: 전환 (D단계로 연결)
```

### C 후킹 필수 요소
```
✅ 가장 강한 감정적 임팩트
✅ 예상을 뒤집는 요소
✅ 시각적으로 명확한 변화
✅ 소리로 강조 (울음, 소리)
✅ 다음 단계 궁금증 유발
```

## Prompt Examples

### C1 - 대반전
```
Flashlight reveals something unexpected.
Not just one fox - three baby foxes huddled behind the mother.
The mother was protecting them all along.
Camera shakes with surprise.
No background music, baby foxes crying, mother whimpering.
```

### C3 - 위기의 절정
```
Two wolves step out from the darkness.
They don't back away, moving closer instead.
The injured fox in arms, no way to run.
Heart pounding, flashlight shaking badly.
No background music, wolves growling, heavy panicked breathing.
```

### C7 - 역할 반전
```
Suddenly the fox lunges toward the person.
Not attacking - there was a snake behind.
The fox scared it away, saved the rescuer.
Standing there panting, looking up.
No background music, snake hissing away, fox breathing hard.
```

## 안티 패턴 (피해야 할 것)

```
❌ 이 구간에서 긴장 떨어뜨림
❌ 예측 가능한 전개
❌ B단계보다 약한 임팩트
❌ 설명/대화로 때움
❌ 액션 없는 감정 장면
```

## D단계 연결 가이드

| C 유형 | → D 추천 전개 |
|--------|--------------|
| 대반전 | 반전의 결과 처리 |
| 감정 폭발 | 관계 심화 |
| 위기 절정 | 탈출/해결 과정 |
| 신기한 행동 | 행동의 결과 |
| 숨겨진 진실 | 진실에 대한 대응 |
| 연쇄 발견 | 전체 해결 |
| 역할 반전 | 새로운 관계 형성 |
