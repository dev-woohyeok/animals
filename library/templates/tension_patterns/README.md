# Tension Patterns (긴장 패턴)

> 고강도 긴장감을 유지하는 스토리 패턴 라이브러리

## Overview

60초 쇼츠에서 **15초마다 후킹 포인트**를 배치하여 시청 지속시간을 극대화하는 패턴들.

## 긴장 곡선 비교

```
일반 패턴 (이탈 발생):
강도
100│      ╱╲
 80│     ╱  ╲
 60│────╱    ╲──────────  ← 45초 이후 이탈
 40│
   └─────────────────────
    0   10   25   40   50  60초


고강도 패턴 (이탈 방지):
강도
100│           ★        ★
 90│          ╱╲      ╱╲
 80│    ╱╲   ╱  ╲    ╱  ╲
 70│   ╱  ╲ ╱    ╲  ╱    ╲
 60│──╱    ▽      ▽       ╲──
   └─────────────────────────
    0   10   25   40   50  60초
        ↑    ↑    ↑    ↑
       B1   C1   D1   E1
      전개 클맥1 클맥2 완결
```

## 5단계 후킹 타임라인 (60초 기준)

| 시간 | 단계 | 코드 | 목적 | 필수 요소 |
|------|------|------|------|----------|
| 0-10초 | 오프닝 | A | "이게 뭐지?" | 즉각적 호기심 |
| 10-25초 | 전개 | B | "설마...?" | 예상 뒤집기 |
| 25-40초 | 클라이맥스1 | C | "와!" | 최고 긴장 |
| 40-50초 | 클라이맥스2 | D | "진짜?" | 2차 위기/반전 |
| 50-60초 | 완결 | E | "결국..." | 감동+구독 유도 |

## Available Patterns

### 1. [Predator Standoff](./predator_standoff.md) (포식자 대치)
늑대, 코요테 등 포식자와의 긴장감 넘치는 대치 상황

### 2. [Time Pressure](./time_pressure.md) (시간 압박)
얼어죽음, 출혈 등 시간 제한이 있는 구조 상황

### 3. [Environmental Crisis](./environmental_crisis.md) (환경 위기)
홍수, 산불, 폭풍 등 자연재해 속 구조

### 4. [Choice Dilemma](./choice_dilemma.md) (선택 딜레마)
여러 동물 중 선택해야 하는 갈등 상황

### 5. [Mystery Reveal](./mystery_reveal.md) (미스터리 공개)
어둠 속 미지의 존재가 밝혀지는 과정

## 긴장 요소 매트릭스

| 패턴 | 포식자 | 시간 | 환경 | 선택 | 미지 |
|------|:------:|:----:|:----:|:----:|:----:|
| predator_standoff | ★★★ | ★ | ★ | ★ | ★★ |
| time_pressure | - | ★★★ | ★★ | ★ | - |
| environmental_crisis | - | ★★ | ★★★ | ★ | ★ |
| choice_dilemma | ★ | ★★ | ★★ | ★★★ | - |
| mystery_reveal | ★★ | ★ | ★ | ★ | ★★★ |

## 핵심 원칙

### 1. 더블 클라이맥스
25초와 50초에 두 번의 절정 배치

### 2. 연속 위기
하나 해결하면 다른 문제 발생

### 3. 가짜 실패
안 될 것 같다가 마지막에 성공

### 4. 환경 악화
시간이 갈수록 상황이 나빠짐

### 5. 감각적 긴장
소리, 어둠, 움직임으로 불안 조성
