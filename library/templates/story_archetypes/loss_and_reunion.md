# Loss & Reunion Archetype (상실 → 재회)

> 소중한 존재를 잃은 후, 예상치 못한 재회로 완성되는 이야기

## Archetype Overview

함께한 시간 동안 깊은 유대를 형성하고, 이별의 아픔을 겪은 후, 시간이 지나 재회하며 감동의 절정에 이르는 스토리 구조.

## Core Elements

### 1. 유대 형성 (Bond Formation)
재회의 감동을 위해 충분한 감정 투자 필요

**필수 장면**:
- 함께하는 행복한 순간들
- 성장 과정 (아기 → 성체)
- 일상적 친밀감
- 서로에게 특별한 의미

### 2. 이별 (Separation)
슬프지만 피할 수 없는 이별

| 이별 유형 | 감정 톤 | 예시 |
|----------|---------|------|
| **자연스러운 독립** | 쓸쓸함, 축복 | 야생으로 돌아감 |
| **원래 가족에게 돌아감** | 슬픔, 수용 | 부모가 데려감 |
| **어쩔 수 없는 상황** | 비통함 | 이사, 환경 변화 |
| **선택** | 갈등, 희생 | 동물을 위한 결정 |

### 3. 상실의 시간 (Time of Loss)
공허함과 그리움의 시간

**시각적 표현**:
- 텅 빈 공간
- 사용하지 않는 물건
- 혼자 남은 존재
- 시간 경과 (계절 변화)

### 4. 재회 (Reunion)
예상치 못한 순간, 감동의 절정

**재회 트리거**:
- 소리 (하울링, 짖음)
- 갑작스러운 출현
- 익숙한 장소로 귀환
- 특별한 날/상황

## Reunion Types

### 1. 세대 연결 (Generational)
```
떠난 동물이 자신의 아기를 데리고 돌아옴
→ "엄마가 그랬던 것처럼"
→ 사랑의 순환, 신뢰의 계승
```

### 2. 우정 확인 (Friendship Validated)
```
성장한 모습으로 돌아와 함께 놀기
→ 변치 않은 유대
→ 시간이 흘러도 기억함
```

### 3. 보은 (Gratitude Return)
```
도움이 필요할 때 나타나 도움
→ 받은 사랑을 갚음
→ 역할 반전
```

### 4. 선택적 귀환 (Chosen Return)
```
야생에서 살 수 있지만 돌아옴
→ 선택한 가족
→ 본능보다 강한 유대
```

## Thematic Messages

1. **진정한 유대는 시간을 초월한다**
2. **놓아주는 것도 사랑이다**
3. **떠나보낸 사랑은 돌아온다**
4. **기다림은 보상받는다**

## Reference Stories

### 엄마가 남긴 선물 (캥거루)
- 유대: 손바닥 위 아기 → 함께 사는 가족
- 이별: 야생 무리에 합류
- 상실: 텅 빈 거실, 사용하지 않는 주머니
- 재회: 2년 후 자신의 아기와 귀환
- 의미: 세대 연결, 신뢰의 계승

### 개구멍으로 찾아온 겨울 손님들 (늑대)
- 유대: 함께 먹고 자고 놀던 시간
- 이별: 부모 늑대가 데려감
- 상실: 혼자 개집에 들어가는 허스키
- 재회: 1년 후 하울링과 함께 방문
- 의미: 우정 확인, 잊지 않았다

## Key Scenes

### 행복한 시간 (몽타주)
```
- 함께 성장하는 모습
- 일상의 행복한 순간들
- 특별한 이정표 (첫 걸음, 첫 뜀 등)
- 친밀한 접촉 (잠자기, 놀기)
```

### 이별 장면
```
- 뒤돌아보며 떠나가는 실루엣
- 작별 인사 (눈빛, 몸짓)
- 점점 작아지는 모습
- 사라지는 순간의 정적
```

### 상실의 시간
```
- 텅 빈 잠자리
- 사용하지 않는 밥그릇
- 창밖을 바라보는 뒷모습
- 시간 경과 표현 (낮→밤, 여름→겨울)
```

### 재회 장면
```
- 소리로 시작 (하울링, 발소리)
- 문 열림 / 등장
- 인식의 순간 (같은 눈, 익숙한 모습)
- 달려가는 순간
- 포옹 / 함께하는 모습
```

## Time Gap Expressions

재회까지의 시간을 효과적으로 표현:

| 시간 경과 | 시각적 표현 |
|----------|-------------|
| 며칠 | 낮/밤 전환 |
| 몇 주 | 달력, 계절 변화 시작 |
| 몇 달 | 계절 완전 변화 |
| 1년+ | 텍스트 오버레이 "1 year later" |

## Emotional Investment Tips

재회 감동을 극대화하려면:

1. **충분한 유대 시간** - 최소 30% 이상을 행복한 시간에 투자
2. **구체적인 기억** - 재회 시 떠올릴 특별한 순간들
3. **시각적 연결** - 같은 눈, 같은 행동으로 동일 캐릭터 인식
4. **이별의 무게** - 상실감을 충분히 느끼게 해야 재회가 감동적
5. **예상치 못한 타이밍** - 기대하지 않던 순간의 귀환
