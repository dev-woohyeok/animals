# Viral Abandonment Pattern (바이럴 유기 패턴)

> 5단계 감정 시퀀스로 시청자를 몰입시키는 바이럴 최적화 패턴

## Pattern Overview

```
강도
100 |  ★ 분노                              ★ 감동/사랑
 90 |  ↑                                  /
 80 | /   ↘                            /
 70 |       ★ 안쓰러움               /
 60 |        \                      /
 50 |          ↘                  ★ 안도/희망
 40 |            ★ 무력감       ↗
 30 |              \          /
 20 |                ↘------★
    |__________________________________________
     Scene1  Scene2-3  Scene4  Scene5-6  Scene7
     (Hook)  (배경)   (바닥)  (전환)    (결말)
```

## 5-Stage Viral Emotion Sequence

| Stage | Emotion | Korean | Trigger | Scene Position |
|-------|---------|--------|---------|----------------|
| 1 | **Anger** | 분노 | 유기/학대 목격 | Scene 1 (Hook) |
| 2 | **Pity** | 안쓰러움 | 무고한 동물의 고통 | Scene 2-3 |
| 3 | **Helplessness** | 무력감 | 화면 너머라 도울 수 없음 | Scene 3-4 |
| 4 | **Relief** | 안도/희망 | 구조자 등장, 상황 전환 | Scene 5-6 |
| 5 | **Love** | 감동/사랑 | 새 가족, 행복한 결말 | Scene 7 |

## Emotional Journey (Detail)

| Position | Phase | Emotion | Intensity | Viewer Reaction |
|----------|-------|---------|-----------|-----------------|
| 0.0 | **Hook** | 분노, 충격 | 100 | "이걸 누가?!" 댓글 폭발 |
| 0.10 | Hook 지속 | 분노 유지 | 95 | 유기자에 대한 적개심 |
| 0.20 | 배경 시작 | 안쓰러움 시작 | 75 | "불쌍해..." 감정 이입 |
| 0.30 | 배경 전개 | 안쓰러움 극대화 | 80 | 동물에 감정 완전 이입 |
| 0.40 | 위기 | 무력감 시작 | 50 | "제발 누가 좀..." |
| 0.50 | **바닥** | 무력감 극대화 | 30 | 화면 너머라 답답함 |
| 0.60 | 전환 시작 | 안도 시작 | 55 | "드디어!" 긴장 풀림 |
| 0.75 | 구조/돌봄 | 안도, 따뜻함 | 75 | 미소, 눈물 |
| 0.90 | 결말 진입 | 감동 상승 | 90 | 가슴 벅참 |
| 1.0 | **결말** | 사랑, 행복 | 100 | 좋아요+저장+공유 |

## Why This Pattern Goes Viral

### 분노 → 공유 동기
- 분노는 SNS에서 가장 강한 공유 동기
- "이 나쁜 놈 봐" → 공유 버튼 클릭
- Hook에서 분노를 터뜨려야 이탈 방지

### 안쓰러움 → 감정 투자
- 무고한 존재의 고통 = 본능적 보호 욕구
- 시청자가 동물 편이 됨
- 영상을 끝까지 볼 이유 생성

### 무력감 → 긴장 유지
- "내가 도울 수 없다"는 답답함
- 스크롤 멈추고 결말 기다림
- 가장 낮은 감정점 = 반등 효과 극대화

### 안도 → 카타르시스
- 무력감 바닥에서 구조자 등장
- 긴장이 한 번에 풀리는 쾌감
- 눈물 트리거

### 감동 → 행동 전환
- 최종 행복 장면 = 좋아요, 저장, 공유
- "세상에 좋은 사람도 있구나"
- 다음 영상도 볼 동기 (구독)

## Scene-Level Emotion Triggers

### Scene 1: Hook - 분노 폭발
**목표**: 3초 안에 분노 유발

| Trigger | Description | Example |
|---------|-------------|---------|
| **목격** | 유기/학대 현장을 직접 보여줌 | CCTV에 찍힌 유기 장면 |
| **증거** | 유기의 흔적 (묶인 줄, 상자) | 벤치에 묶인 줄, 빈 상자 |
| **대비** | 무고한 동물 vs 잔인한 행위 | 꼬리 흔드는 강아지를 밀쳐내는 손 |
| **날씨** | 극한 환경에 방치 | 폭우, 한겨울, 폭염 |

**Camera**: 1인칭 POV, CCTV, 블랙박스 - 실제 영상처럼

### Scene 2-3: 배경 - 안쓰러움 구축
**목표**: 동물에 완전히 감정 이입

| Trigger | Description | Example |
|---------|-------------|---------|
| **기다림** | 주인이 돌아오길 기다리는 모습 | 같은 자리에서 움직이지 않음 |
| **눈빛** | 슬프고 혼란스러운 표정 | 카메라를 올려다보는 큰 눈 |
| **작은 몸** | 환경 대비 작고 연약한 존재감 | 넓은 도로 한가운데 작은 강아지 |
| **소리** | 울음, 낑낑거림 | 작게 낑낑대며 두리번거림 |

**Camera**: 가까이 다가가는 핸드폰 촬영, 흔들림

### Scene 3-4: 바닥 - 무력감 극대화
**목표**: 상황이 더 나빠지는 것처럼 보이게

| Trigger | Description | Example |
|---------|-------------|---------|
| **시간 경과** | 점점 지쳐가는 모습 | 날이 어두워지고, 비가 오기 시작 |
| **무시** | 지나가는 사람들이 무시 | 행인들이 그냥 지나감 |
| **위험** | 추가 위험 요소 | 차들이 쌩쌩 지나가는 도로 |
| **포기** | 동물이 포기하는 듯한 모습 | 고개를 숙이고 웅크림 |

**Camera**: 멀리서 지켜보는 구도, 답답한 거리감

### Scene 5-6: 전환 - 안도와 희망
**목표**: 무력감에서 한 번에 반전

| Trigger | Description | Example |
|---------|-------------|---------|
| **구조자** | 멈추는 차, 다가오는 사람 | 차에서 내려 달려오는 여자 |
| **첫 접촉** | 동물을 처음 안는 순간 | 떨리는 손으로 안아 올림 |
| **안전** | 위험에서 벗어남 | 따뜻한 차 안, 담요 |
| **반응** | 동물의 긍정적 반응 | 꼬리 흔들기, 얼굴 핥기 |

**Camera**: 가까이 다가간 핸드폰, 한 손으로 촬영하며 한 손으로 안음

### Scene 7: 결말 - 감동과 사랑
**목표**: 최대 감동 → 좋아요/공유 유도

| Trigger | Description | Example |
|---------|-------------|---------|
| **새 환경** | 따뜻한 새 집 | 소파 위, 자기 침대, 장난감 |
| **행복** | 동물의 행복한 모습 | 뛰어놀기, 배 보이며 눕기 |
| **유대** | 구조자와의 유대감 | 함께 소파에서 잠들기 |
| **성장** | Before/After 대비 | 처음 vs 지금 비교 |

**Camera**: 일상 홈비디오, 핸드폰 셀카 구도

## Story Structure for This Pattern

### 1. Hook (0.0 - 0.10) - 분노
- 가장 충격적인 유기/학대 순간
- 단일 프레임, 서브샷 없음
- 시청자가 "이걸 누가?!" 반응

### 2. 배경 (0.10 - 0.30) - 안쓰러움
- 유기 과정을 시간순으로 보여줌
- 동물의 혼란, 기다림, 슬픔
- 시청자가 동물에 감정 이입 완료

### 3. 바닥 (0.30 - 0.50) - 무력감
- 상황이 악화됨 (날씨, 시간, 위험)
- 아무도 도와주지 않음
- 동물이 지쳐감
- **감정 곡선의 최저점**

### 4. 전환 (0.50 - 0.75) - 안도
- 구조자 등장
- 동물을 안아 올림
- 안전한 곳으로 이동
- 첫 돌봄 (밥, 담요, 병원)

### 5. 결말 (0.75 - 1.0) - 감동/사랑
- 새 집에서의 행복한 일상
- 구조자와의 유대
- 처음과 완전히 다른 모습
- **감정 곡선의 최고점**

## When to Use This Pattern

### Best For
- 유기/버림받은 동물 스토리
- 도로/고속도로 유기 스토리
- CCTV/블랙박스 스타일 스토리
- 구조 후 Before/After 스토리
- **바이럴 조회수 극대화가 목표일 때**

### Avoid When
- 가벼운 일상/유머 스토리
- 다른 종 간 우정 스토리
- 야생 동물 방생 스토리
- 이별/재회가 핵심인 스토리

### Best Animal Types
- 강아지 (가장 높은 공감도)
- 고양이 (미스터리한 매력)
- 작은 동물 (토끼, 고슴도치 - 연약함 극대화)

## Reference Stories

### 고속도로 허스키 유기
- Hook: 고속도로에서 차 문 열고 허스키를 밀어냄
- 안쓰러움: 차를 따라 달리는 허스키
- 무력감: 고속도로 한가운데서 멈춰선 허스키
- 안도: 다른 차가 멈춰서 구조
- 감동: 새 가족과 행복한 생활

### 코기 유기 영상
- Hook: 남자가 코기를 발로 밀쳐냄
- 안쓰러움: 다시 돌아가려는 코기
- 무력감: 혼자 남겨진 코기
- 안도: 지나가던 사람이 안아 올림
- 감동: 구조자의 가족이 됨
