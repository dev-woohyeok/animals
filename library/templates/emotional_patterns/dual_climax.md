# Dual Climax Pattern (이중 절정 패턴)

> 두 번의 감정적 절정점을 가진 고강도 감정 곡선

## Pattern Overview

```
강도
100 |           ★ (제1절정: 비극/충격)
 90 |        ↗      ★ (제2위기)           ★ (제2절정: 결심/사랑)
 80 |       /          \                  /
 70 |  ★--/              \              /
 60 | /                    \          /
 50 |                        ★------★
 40 |                        (이완/안도)
    |_____________________________________________
      도입    전개    위기       해결      결말
```

## Emotional Journey

| Position | Phase | Emotion | Intensity |
|----------|-------|---------|-----------|
| 0.0 | 도입 | 불안, 호기심 | 60 |
| 0.15 | 도입→전개 | 연민, 신뢰 시작 | 70 |
| 0.25 | 전개 | 긴장, 결심 | 65 |
| 0.40 | 전개→위기 | 충격, 공포 | 95 |
| 0.50 | **위기 (제1절정)** | **비통, 슬픔** | **100** |
| 0.60 | 위기→해결 | 공포, 위기 | 90 |
| 0.70 | 해결 | 안도 | 55 |
| 0.80 | 해결 | 따뜻함 | 75 |
| 0.90 | 해결→결말 | 이별의 슬픔 | 70 |
| 1.0 | **결말 (제2절정)** | **사랑, 희망** | **95** |

## Pattern Characteristics

### 핵심 특징
- **제1 절정**: 스토리 중반에 비극적 사건 (상실, 죽음, 위기)
- **이완 구간**: 잠시 안도와 따뜻함으로 관객 호흡 조절
- **제2 위기**: 새로운 갈등 또는 선택의 순간
- **제2 절정**: 감정적 결심과 희망적 전환

### 효과
- 관객이 두 번의 강렬한 감정 경험
- 첫 번째 충격 후 이완으로 감정 리셋
- 마지막 결심이 더 큰 카타르시스 제공

## Story Structure for This Pattern

### 1. 도입 (0.0 - 0.15)
- 평범한 상황에서 예상치 못한 조우
- 동물이 인간에게 도움 요청 (간절한 눈빛, 울음)
- 관객의 호기심과 연민 유발

### 2. 전개 (0.15 - 0.40)
- 인간이 동물을 따라가기로 결심
- 신뢰 관계 형성 시작
- 긴장감 점진적 상승

### 3. 위기 - 제1절정 (0.40 - 0.60)
- **충격적인 비극 발견** (죽음, 상실)
- 동물의 처절한 슬픔
- 인간도 함께 감정 이입
- 새로운 위험 요소 등장

### 4. 해결 (0.60 - 0.90)
- 위험에서 탈출/구조
- 안전한 공간에서의 회복
- 따뜻한 돌봄과 유대 형성
- **이별/선택의 순간** (떠날 것인가 vs 함께할 것인가)

### 5. 결말 - 제2절정 (0.90 - 1.0)
- 동물의 간절한 호소
- 인간의 결심
- **새로운 가족의 탄생**

## Reference Story

**한밤의 숲에서 만난 아기 여우**
- 제1절정: 엄마 여우의 죽음 발견
- 제2절정: 아기 여우를 데려가기로 결심

## When to Use This Pattern

### Best For
- 구조 스토리 (동물이 인간에게 도움 요청)
- 상실 후 새 가족 형성
- 위험에서의 탈출
- 강렬한 감정적 임팩트 필요시

### Avoid When
- 가벼운 일상 스토리
- 유머 중심 콘텐츠
- 아동 대상 콘텐츠 (너무 강렬할 수 있음)

## Template Variables

```yaml
pattern: dual_climax
first_climax:
  type: "tragedy/shock"  # tragedy, shock, danger, loss
  intensity: 100
  event: "{{TRAGIC_EVENT}}"

relaxation:
  duration: "0.60-0.80"
  emotion: "relief, warmth"

second_climax:
  type: "decision/love"  # decision, reunion, love
  intensity: 95
  event: "{{RESOLUTION_EVENT}}"
```
